# 提示词工程

> 定位：**通用正向描述词 + 负向提示词 + 角色属性词库**（供各模型参考，具体写法见 [[参数速查表]] 模型卡 + [[提示词模板]]）。
> 说明：自然语言模型（即梦/Seedream/Flux/可灵/万相）以完整句子为主，tag 语法已废弃；负面词仅即梦/Seedream/万相写，Flux 不写。

## 一、自然语言描述公式

```
[主体] + [场景] + [光线] + [构图/视角] + [材质细节]
（完整句子，主体放句首，中英文均可）
```

## 二、质量提升（自然语言模型）

> 自然语言模型**不堆质量词**（masterpiece/8k 这类 tag 无效），靠「具体描述 + 摄影术语」提升质量。可用的质感词：cinematic lighting、shallow depth of field、film grain、85mm compression、subsurface scattering。

## 三、负面描述词（仅即梦/Seedream/万相写，Flux 不写）

```
deformed, bad anatomy, extra fingers, fused fingers,
blurry, watermark, text, signature, low quality
```

## 四、角色属性词库（人物外貌描述用）

- **体型**：slim, athletic, muscular, plump, petite, tall, curvy, lean
- **脸型**：oval face, round face, square jaw, heart-shaped face, angular features
- **发型**：long straight hair, short bob, ponytail, braided, messy bun, buzz cut, wavy hair, curly
- **发色**：black hair, brown hair, blonde, silver/grey hair, red/auburn hair, blue/pink (fantasy)
- **眼型**：almond eyes, round eyes, monolid, upturned eyes, deep-set eyes, sharp eyes
- **表情**：serious, smiling, determined, melancholic, fierce, calm, innocent, cold
