> 来源：丹尼艾尔·阿里洪《电影语言的语法》
> 用途：分镜大师生成分镜提示词时的语法参考

## 一、AI 分镜生成检查清单（分镜生成必查）

### 1.1 每场戏前先问

| 问题 | 决策 |
|------|------|
| 场景类型 | 对话 / 动作 / 静态情绪 / 追逐 / 群像 |
| 人物数量 | 1 / 2 / 3 / 4+ |
| 人物关系 | 平等 / 主导-从属 / 对立 / 同盟 |
| 核心动作 | 接近 / 分离 / 对峙 / 追逐 / 静止 |
| 情绪目标 | 亲密 / 紧张 / 对抗 / 仪式 / 刺激 |

### 1.2 镜头设计检查项

- [ ] 关系线是否用两演员头部确定？
- [ ] 摄影机是否选定关系线一侧并坚持到底？
- [ ] 越轴是否有充分动机和过渡？
- [ ] 景别是否有层次变化？
- [ ] 机位是外反拍/内反拍/平行/直角/共同视轴中的哪一种？是否合理？
- [ ] 对话场面是否有交代镜头、主镜头、反应镜头？
- [ ] 运动剪辑是否满足位置/动作/视线三匹配？
- [ ] 切点是否在动作中段？
- [ ] 方向转换是否用中性镜头或顿歇过渡？
- [ ] 动作场面是否有纵深递进、分解一击、主观 POV、手持短切？

### 1.3 快速决策表

| 场景需求 | 推荐镜头语法 |
|----------|--------------|
| 环境环视 / 主观目击 | 中速横摇，半圈以内 |
| 发现 / 反应 | 视线跟随摇摄，动机与反应同镜 |
| 角色进入新区域 | 移动镜头提前到达，或人物出画接固定镜头 |
| 追逐戏 | 成对摇镜 + 平行剪辑 + 长焦虚化 + 遮挡转场 |
| 群像 / 大场面过渡 | 升降机高台俯拍，从静到动 |
| 动作高潮一击 | 中景起势 → 同视轴近景完成，或被击者出画/摇摄倒下 |
| 混战 / 群斗 | 纵深层次递进，多动作从后景移向前景 |
| 手持追逐 | 短于 5 秒，利用颠簸感增强刺激 |
| 方向反转但保持连续 | 轨道移动 + 中途半圈摇摄转向另一侧 |

## 二、核心分镜语法（通用规则）

### 2.1 轴线与越轴

- 关系线 = 两演员**头部**之间的连线（不以身体姿态为准）
- 摄影机只在关系线一侧拍摄，选定后坚持到底
- 越轴必须有明确动机 + 过渡（演员移动 / 摄影机跟随 / 中性镜头 / 顿歇）
- 严禁无动机越轴

### 2.2 三匹配原则（镜头切换必满足）

1. **位置匹配**：同一视轴切换景别，人物保持在银幕同一侧
2. **动作匹配**：连续动作的两个镜头中，动作方向一致
3. **视线匹配**：互相对视的两人画面中方向相反

### 2.3 切点选择

- 在**动作进行中**切换（动作过半、重心转移、方向改变瞬间），而非动作起止处

### 2.4 景别层次

- 同一场景交替使用不同景别，不要整场只用一个景别
- 越近越亲密/压迫，越远越强调空间关系

### 2.5 动作场面设计

- **分解强烈一击**：一拳/一踢分两个镜头（中景起势 → 同视轴近景完成）
- **纵深递进**：动作从后景逐层推进到前景
- **主观 POV + 手持短切**（单镜头 ≤5 秒）增强追逐刺激

### 2.6 对话场面

- 双人：外反拍（客观）/ 内反拍（主观）/ 过肩（定位+代入）
- 三人：三角形布局 + 枢轴演员
- 四人及以上：主镜头先行 → 局部切入 → 反应镜头
