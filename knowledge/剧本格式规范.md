# 剧本格式规范

## 一、标准好莱坞格式

### 场景头部 (Scene Heading / Slug Line)
```
INT./EXT. [地点] - [时间] 

示例：
INT. 咖啡店 - 白天
EXT. 城市街道 - 黄昏
INT./EXT. 汽车内 - 夜晚
```

### 三要素
| 要素 | 说明 | 常见取值 |
|------|------|---------|
| 内/外景 | INT.（内景）/ EXT.（外景）/ INT./EXT.（内外结合） | INT. EXT. INT./EXT. |
| 地点 | 场景具体位置 | 办公室、卧室、街道 |
| 时间 | 时间段或特殊时间 | 白天/夜晚/黄昏/黎明/稍后/连续 |

### 动作描写 (Action / Description)
- 以段落形式描述画面内容
- 角色首次出场时用**全大写**标注角色名，附年龄和关键特征
- 重要道具、声音、特效也用大写标注

示例：
```
ZHANG WEI（35岁，精瘦，眼窝深陷）推门而入。他穿着一件
褪色的军大衣，手里捏着一个牛皮纸信封。

门外的街道上传来警笛声，越来越近。
```

### 角色名 (Character Cue)
- 对白上方居中，全大写
- 首次出场可附带简要说明

### 对白 (Dialogue)
- 居中，角色名正下方
- 可附带括号内的表演提示：（轻声）、（停顿）、（苦笑）

### 转场 (Transition)
- 右对齐，常见：CUT TO: / FADE OUT. / DISSOLVE TO: / SMASH CUT TO:

## 二、中文剧本常见格式

### 场次格式
```
第X场
地点：XXX
时间：XXX
人物：XXX（可附角色状态）

[动作/画面描写]

角色名：（表演提示）对白内容
```

### 小说式剧本
- 介于小说和剧本之间
- 场景头部较简略或直接融入叙事
- 动作描写与对白交替出现，段落感强
- **解析策略**：手动提取人物→场景→动作节拍

## 三、解析策略

### 识别角色
1. 搜索全大写的角色名行（对白上方）
2. 首次出场的动作描写（带年龄/外貌）
3. "人物："或"登场人物："汇总列表

### 提取人物属性
| 属性 | 来源位置 | 格式提示 |
|------|---------|---------|
| 姓名 | 角色名行、人物列表 | 全大写或加粗 |
| 年龄 | 首次动作描写 | 括号内数字或描述 |
| 外貌 | 首次动作描写 | 形容词集中段落 |
| 职业/身份 | 动作描写、对白提及 | 名词+语境 |
| 性格特征 | 对白风格、动作描写 | 副词、动词选择 |
| 服饰 | 特定场景动作描写 | 颜色+款式 |

### 提取场景信息
| 属性 | 来源 |
|------|------|
| 地点 | 场景头部"地点："字段 |
| 时间 | 场景头部"时间："字段 |
| 天气 | 动作描写中的环境描述 |
| 氛围 | 动作描写中的形容词、动词 |
| 空间特征 | 动作描写中的空间描述 |
| 情绪基调 | 剧本情绪词汇、对话语气 |

### 拆解分镜
1. 按**场景头部**切大段落
2. 每个场景内按**动作节拍**（位置变化/人物进出/关键动作）切镜头
3. 对白段落对应一个或多个镜头
4. 转场标记作为镜头切换点

### 镜头划分依据
- 新角色进入画面 → 切
- 角色移动至新位置 → 切
- 情绪转折点 → 切（可能换景别）
- 时间省略/跳跃 → 切
- 转场标识 → 切
- 重要道具亮相 → 可能插入镜头

## 四、Fountain 格式识别

Fountain 是纯文本剧本标记语言，特征如下：
- 场景头部以 `INT.` `EXT.` 等开头
- 角色名全大写独占一行
- 动作描写为普通段落
- 以 `.` 开头表示转场

解析策略同上，但解析更自动化。

## 五、模糊信息处理

剧本中常见模糊描述，建议这样处理：

| 模糊描述 | 确认策略 | 提示词策略 |
|---------|---------|-----------|
| "一间普通的办公室" | 确认时代/风格/城市 → 推断 | 用通用词：modern office, neutral design |
| "他穿得很得体" | 确认身份/场合 → 推断 | 用场合关键词：business formal, tailored suit |
| "气氛紧张" | 不追问（情绪是主观的） | 用灯光/构图暗示：harsh shadows, close-up framing |
| "未来城市" | 确认风格（赛博/乌托邦/废土） | 确认后再细化 |

### 主动确认规则
以下情况必须主动确认：
- 角色年龄、性别不明确 → 询问
- 时代背景缺失 → 询问（古装/现代/未来）
- 风格要求缺失 → 首轮默认"电影写实风"，告知可切换
- 多角色关系混乱 → 列出推断的关系，请确认
