# 角色微表情库

> **用途**：生成人物镜头/分镜图提示词时，按情绪精确描述面部肌肉、眉眼、嘴部、头部姿态与肢体动作，避免"统一怒脸/统一笑脸"的公式化表演。
> **使用方式**：先确定角色当前情绪（含复合情绪），再查对应条目；写提示词时组合【面部】【眉眼】【嘴部】【头部】【肢体】【呼吸】六个维度，微表情用 2-4 个细节词即可，不必全堆。

## 零、微表情底层原理（速记）

- **真实情绪 ≤ 0.5 秒**：真表情在脸上停留极短，写提示词时微表情要"短暂、局部、不对称"，不要整脸均匀变化
- **不对称是真实感来源**：单侧挑眉、一边嘴角抽动 > 对称表情
- **眉毛 > 眼睛 > 嘴**：情绪辨识度最高的是眉毛（尤其眼轮匝肌与皱眉肌联动），其次是眼睑，最后才是嘴
- **克制 > 爆发**：压抑情绪的细节（嘴角下拉幅度极小、眼皮微垂）比夸张表情更高级
- **眨眼频率是情绪仪表盘**：平静 15-20 次/分，紧张/说谎 25-40 次/分，专注/对峙可降到 5-10 次/分
- **呼吸优先于动作**：激烈情绪先写胸口起伏/鼻翼翕动，再写四肢动作

## 一、基础情绪微表情

### 1. 喜（真实开心）
| 维度 | 细节 |
|------|------|
| 面部 | 眼轮匝肌收缩，苹果肌上提，颧骨隆起；法令纹加深 |
| 眉眼 | 眉毛自然舒展，眉尾微垂；下眼睑微微上弯形成"笑眼"；眼睛略眯 |
| 嘴部 | 嘴角向两侧+上方自然牵拉，露出上排牙；大笑时眼角出现鱼尾纹 |
| 头部 | 微微后仰或侧偏，幅度小 |
| 肢体 | 肩膀放松下沉，双手自然；轻快时重心略上提，可能轻轻拍手/耸肩 |
| 呼吸 | 平缓，笑声伴随短促呼气 |
| 提示词 | genuine smile, crinkled eye corners, raised cheekbones, relaxed brows, soft laugh lines |

### 2. 喜（礼貌假笑 / 营业笑）
| 维度 | 细节 |
|------|------|
| 面部 | 只有嘴部在笑，眼轮匝肌不参与——眼睛无笑意（关键区分点） |
| 眉眼 | 眉毛不动，眼睛正常睁大，无眯眼 |
| 嘴部 | 嘴角上拉但牙齿咬合紧，或只露上排牙不露下排；笑纹浅 |
| 头部 | 端正不偏，微点头 |
| 肢体 | 身体距离感保持，手部无开放动作 |
| 提示词 | polite smile, mouth-only smile, eyes without warmth, tight jaw, superficial grin |

### 3. 怒（轻微不满）
| 维度 | 细节 |
|------|------|
| 面部 | 皱眉肌轻微收缩，眉心出现两道浅竖纹；脸颊肌肉微绷 |
| 眉眼 | 眉毛内侧向下压（不是整条眉下压），外眉尾略扬；上眼睑略收紧，目光变锐 |
| 嘴部 | 嘴角下拉幅度极小（1-2mm），嘴唇抿紧变薄，下巴微前伸 |
| 头部 | 轻微前倾，下巴微抬或持平 |
| 肢体 | 双臂交叉或手部握拳未紧，脚重心略前移；呼吸略加深 |
| 提示词 | subtle irritation, slight brow furrow, tightened jaw, thinned lips, narrowed eyes |

### 4. 怒（中度愤怒）
| 维度 | 细节 |
|------|------|
| 面部 | 皱眉肌+降眉间肌强烈收缩，眉心深竖纹；鼻翼微张；脸颊绷紧 |
| 眉眼 | 双眉整体下压，眉间距离缩短；眼睛瞪大或半眯（二选一，半眯更危险感）；上眼睑上提露出眼白上缘 |
| 嘴部 | 嘴唇抿成一条线或微微张开咬牙；下唇微前突；嘴角向下明显 |
| 头部 | 下巴明显前伸，头微低视线向上瞪（攻击姿态）；或头微仰俯视 |
| 肢体 | 双拳紧握，肩胛骨收紧，胸廓扩张；或单手指点/握拳砸桌 |
| 呼吸 | 急促，鼻息重，胸口起伏明显 |
| 提示词 | visible anger, deeply furrowed brows, flared nostrils, clenched jaw, bared teeth slightly, aggressive forward lean, fists clenched |

### 5. 怒（暴怒失控）
| 维度 | 细节 |
|------|------|
| 面部 | 整个面部肌肉紧绷扭曲，青筋（太阳穴/额头）隐现；眼球充血感 |
| 眉眼 | 眉毛拧成倒八字，眉间深沟；眼睛瞪到最大，或瞬间眯成缝再瞪开；眨眼几乎停止 |
| 嘴部 | 呲牙露齿，嘴唇张开；或咬紧后槽牙腮帮鼓出；口水飞溅（特写可用） |
| 头部 | 头颈部前倾，或有轻微颤抖；脖子筋暴起 |
| 肢体 | 全身肌肉绷紧，或摔砸动作的前摇；手部青筋；步幅大而重 |
| 呼吸 | 剧烈喘息，鼻翼大幅翕动 |
| 提示词 | explosive rage, contorted face, bulging veins, bared teeth, wide glaring eyes, trembling rage, veins on neck |

### 6. 哀（轻度悲伤 / 失落）
| 维度 | 细节 |
|------|------|
| 面部 | 降眉肌牵拉，眉心略抬（悲伤眉：眉内侧上抬）；颧骨下垂感 |
| 眉眼 | 眉毛内侧上挑、外侧下垂（八字眉）；上眼睑略垂，眼神失去焦点；眨眼变慢 |
| 嘴部 | 嘴角自然下垂，下唇微微外翻；或嘴唇放松微张（失神态） |
| 头部 | 略低头，视线向下或放空 |
| 肢体 | 肩膀塌陷，双手无力垂放；走路变慢、步伐拖沓 |
| 提示词 | subtle sadness, inner brows raised, downturned mouth, unfocused gaze, drooping shoulders |

### 7. 哀（痛哭）
| 维度 | 细节 |
|------|------|
| 面部 | 眼轮匝肌剧烈收缩挤压眼睛；眉头紧皱向上拱；鼻翼张大；脸颊因抽泣颤动 |
| 眉眼 | 眉毛拧成波浪状（内上外下）；眼睛闭紧或半闭，眼睑红肿；泪水盈眶-滑落 |
| 嘴部 | 嘴角向两侧下咧，嘴巴张大（嚎哭）或抿紧发抖（忍哭）；下唇颤抖 |
| 头部 | 低头，下巴颤抖；或仰头试图止泪 |
| 肢体 | 双手捂脸/抱臂/蜷缩；肩膀剧烈抖动抽泣 |
| 呼吸 | 抽噎，呼吸断续（写"hiccup-like sobs"） |
| 提示词 | heavy crying, squeezed shut eyes, trembling lips, tears streaming, convulsive sobs, shaking shoulders |

### 8. 哀（压抑悲伤 / 强忍眼泪）★高级
| 维度 | 细节 |
|------|------|
| 面部 | 面部肌肉极力控制，偶有微小抽动；眉心轻蹙后迅速舒展（想压住） |
| 眉眼 | 眉毛微微颤抖（不明显的波浪感）；眼皮微垂但努力睁着；眼眶泛红含泪不落 |
| 嘴部 | 嘴角轻微下拉又抿紧，嘴唇绷成一条薄线；下颌肌肉咬紧（咬后槽牙） |
| 头部 | 微微侧低，用侧脸面对镜头；或点头动作带停顿 |
| 肢体 | 手指无意识攥紧衣角/杯子；吞咽动作明显（喉结滚动）；转身动作刻意放慢 |
| 呼吸 | 深吸一口气然后缓慢呼出（写"shallow controlled breathing"） |
| 提示词 | suppressed grief, trembling lower lip, red-rimmed eyes, holding back tears, subtle jaw clench, forced composure |

### 9. 惧（紧张不安）
| 维度 | 细节 |
|------|------|
| 面部 | 眼轮匝肌紧张，上眼睑抬起露出较多眼白；额肌紧绷额纹明显 |
| 眉眼 | 眉毛平直上抬；眼睛睁大但目光游移不敢直视 |
| 嘴部 | 嘴唇微张或抿紧；嘴唇发干可能舔唇 |
| 头部 | 微缩脖子，头向后缩；视线低垂或快速扫视 |
| 肢体 | 双手绞在一起/搓手指；肩部耸起；身体重心后倾；坐姿僵硬 |
| 呼吸 | 浅而快，胸腔起伏小 |
| 提示词 | nervous tension, raised upper eyelids, darting eyes, hunched shoulders, fidgeting fingers, shallow breathing |

### 10. 惧（极度恐惧）
| 维度 | 细节 |
|------|------|
| 面部 | 面部肌肉僵住；瞳孔放大（特写写"dilated pupils"）；额纹全开 |
| 眉眼 | 眉毛高抬且拉直；眼睛瞪到最大，眼白充分露出，眨眼几乎停止 |
| 嘴部 | 嘴巴张开（尖叫前态）或僵硬微张；嘴唇发白 |
| 头部 | 头部僵住或轻微后仰；眼球缓慢移动不敢眨眼 |
| 肢体 | 身体僵直或后退；手部抬起做防御姿态（掌心向外）；或双手捂嘴 |
| 呼吸 | 屏息后短促喘息（写"frozen, barely breathing"） |
| 提示词 | sheer terror, wide unblinking eyes, dilated pupils, frozen expression, defensive palms, rigid posture |

### 11. 惊（惊讶）
| 维度 | 细节 |
|------|------|
| 面部 | 额肌瞬间收缩，额头出现横向皱纹；眼睑快速上提 |
| 眉眼 | 眉毛整条高抬（短促）；眼睛瞬间睁大，0.5 秒后恢复（真实惊讶极短） |
| 嘴部 | 嘴巴自然张开成 O 形（不是刻意张大）；嘴唇放松 |
| 头部 | 无意识快速后仰或向一侧偏 |
| 肢体 | 身体突然静止半拍；手部动作中断 |
| 提示词 | genuine surprise, raised eyebrows, wide eyes, open mouth, brief freeze |

### 12. 厌（厌恶 / 嫌弃）
| 维度 | 细节 |
|------|------|
| 面部 | 提上唇肌收缩，鼻翼上提；鼻梁出现皱褶（嫌恶鼻）；上唇轻微上翘 |
| 眉眼 | 眉毛压低；眼睛微眯或视线偏移不愿正视 |
| 嘴部 | 上唇单侧上翘（不对称），或嘴角单侧下拉；嘴唇抿紧 |
| 头部 | 头微微后仰拉开距离；或侧头避开 |
| 肢体 | 身体后退半步；手部做挡隔动作；可能撇嘴+扭头 |
| 提示词 | disgust, wrinkled nose, raised upper lip, narrowed eyes, slight recoil, turned-away head |

### 13. 轻蔑（不屑）
| 维度 | 细节 |
|------|------|
| 面部 | 单侧嘴角微上扬（不对称冷笑）；眼皮半垂 |
| 眉眼 | 眉毛微挑（单侧）；眼睛半眯俯视 |
| 嘴部 | 单侧嘴角上撇（写"one-sided smirk"）；或向下撇（写"sneer"） |
| 头部 | 下巴微抬，头略后仰；视线自上而下 |
| 肢体 | 双臂环抱；或单手整理袖口/衣领（漫不经心）；身体重心单侧 |
| 提示词 | contempt, one-sided smirk, half-lidded eyes, raised chin, dismissive posture |

### 14. 羞（害羞 / 尴尬）
| 维度 | 细节 |
|------|------|
| 面部 | 脸颊泛红（写"blush"）；目光闪躲 |
| 眉眼 | 眉毛微垂；眼睛向下看或快速避开对视；眨眼加快 |
| 嘴部 | 嘴唇抿起内收（抿嘴笑）；或轻咬下唇 |
| 头部 | 低头，下巴缩向胸口；或侧头用手挡脸 |
| 肢体 | 手指绞衣角/摸后颈/摸头发；身体微微扭转；脚尖对内侧 |
| 提示词 | shyness, blushing cheeks, averted gaze, bitten lip, lowered head, fidgeting |

### 15. 思（沉思 / 专注）
| 维度 | 细节 |
|------|------|
| 面部 | 表情静止；眼球微动（思考中） |
| 眉眼 | 眉毛轻微压低或微皱；眼睛半眯聚焦远处；或眼神失焦放空 |
| 嘴部 | 嘴唇微抿；或下唇轻咬；或手指轻触嘴唇 |
| 头部 | 微微歪头（侧头思考）；或低头手托下巴 |
| 肢体 | 手托腮/捏下巴/交叉于胸前；身体前倾支肘 |
| 提示词 | pensive, distant gaze, slightly furrowed brow, hand on chin, tilted head |

## 二、复合情绪微表情（视频学习重点）

### 16. 强忍怒意（表面平静内里翻涌）★高频
| 维度 | 细节 |
|------|------|
| 面部 | 面部表面平静，但颞下颌关节处肌肉鼓动（咬牙的侧写）；眉心偶现浅纹又松开 |
| 眉眼 | 上眼睑微微收紧（压抑的瞪视感）；眼神稳定但温度下降；眨眼变慢 |
| 嘴部 | 嘴唇放松状但嘴角线绷直；偶尔吞咽 |
| 头部 | 保持水平，微点头动作僵硬 |
| 肢体 | 双手插兜握拳/背后握拳；指节泛白；坐下时大腿紧绷 |
| 提示词 | restrained anger, calm facade, jaw muscle twitching, cold steady gaze, white-knuckled fist |

### 17. 悲喜交加（含泪微笑）★经典
| 维度 | 细节 |
|------|------|
| 面部 | 眼轮匝肌收缩（笑眼）+ 泪腺同时启动（含泪）——矛盾组合即真实 |
| 眉眼 | 眉毛内侧微抬（悲）+ 下眼睑上弯（喜）；眼眶泛红 |
| 嘴部 | 嘴角上翘（微笑）但嘴唇颤抖；或微笑到一半嘴角下撇 |
| 头部 | 微低头或侧偏，视线移开 |
| 肢体 | 轻轻摇头（不敢相信）；或握拳抵唇 |
| 提示词 | bittersweet smile, teary eyes with gentle smile, trembling smile, mixed emotion, glossed eyes |

### 18. 强装镇定（内心恐慌）
| 维度 | 细节 |
|------|------|
| 面部 | 试图维持微笑但面部肌肉僵硬；偶有细微抽动 |
| 眉眼 | 眉毛僵住不动；眼神微微发散，瞳孔略放大 |
| 嘴部 | 笑容维持过久（超过2秒即假）；说话时嘴唇干涩 |
| 头部 | 点头幅度夸张（过度配合）；头部偶有微颤 |
| 肢体 | 手指无意识敲击/转笔；腿轻抖；喝水动作机械 |
| 提示词 | forced calm, stiff smile, unnaturally steady gaze, slight tremor, nervous micro-gestures |

### 19. 心虚（说谎 / 遮掩）
| 维度 | 细节 |
|------|------|
| 面部 | 摸鼻子/摸耳朵（自触安慰）；面部微红 |
| 眉眼 | 眨眼频率突然加快；视线左右飘移后迅速回归（写"briefly averted gaze"） |
| 嘴部 | 说话前舔唇；咬唇；或语速突然变化 |
| 头部 | 回答前微低头或侧头；点头与说话不同步 |
| 肢体 | 手部触碰颈部/衣领；身体轻微后仰；脚转向门口方向（潜意识逃离） |
| 提示词 | guilt, increased blinking, nose touching, averted eyes, defensive body language |

### 20. 深情凝望（爱意）
| 维度 | 细节 |
|------|------|
| 面部 | 面部肌肉完全放松；微光感（写"softened features"） |
| 眉眼 | 眉毛舒展略抬；下眼睑轻微上提（温柔注视）；眼睛微弯 |
| 嘴部 | 嘴角自然微扬；嘴唇微张（欲言又止）；或轻咬下唇 |
| 头部 | 头微歪（感兴趣信号）；缓缓靠近 |
| 肢体 | 身体前倾；手部靠近但未触碰；呼吸放缓 |
| 提示词 | loving gaze, soft eyes, gently curved lips, tilted head, leaning closer, tender expression |

### 21. 绝望（心死）
| 维度 | 细节 |
|------|------|
| 面部 | 面部肌肉完全松弛下垂（无表情管理）；眼神空洞 |
| 眉眼 | 眉毛平直无弧度；眼睛半睁无神，瞳孔无聚焦；眨眼极慢或停止 |
| 嘴部 | 嘴唇微张放松；嘴角无下垂（连悲伤都无力调动） |
| 头部 | 头微垂，动作缓慢 |
| 肢体 | 身体松垮，瘫坐/靠墙滑落；手无力松开物品 |
| 提示词 | hopelessness, empty hollow eyes, slack expressionless face, lifeless posture, listless movements |

### 22. 得意（暗自窃喜）
| 维度 | 细节 |
|------|------|
| 面部 | 努力压住笑意但苹果肌鼓起；眉眼间藏不住愉悦 |
| 眉眼 | 眉毛微挑；眼睛亮而有神，偶有闪烁（写"gleam in eyes"） |
| 嘴部 | 抿嘴憋笑；或嘴角快速上扬又压平 |
| 头部 | 微微后仰；或轻晃头（得瑟） |
| 肢体 | 小动作轻快：转笔、整理衣领、哼歌；走路带节奏 |
| 提示词 | smug satisfaction, suppressed grin, gleaming eyes, buoyant energy, playful swagger |

### 23. 警惕（戒备）
| 维度 | 细节 |
|------|------|
| 面部 | 表情收敛，无笑容；额头微绷 |
| 眉眼 | 眉毛平直微压；眼睛半眯扫视，视线在目标间快速移动；眨眼减少 |
| 嘴部 | 嘴唇抿紧成线；或下颌微收 |
| 头部 | 保持低姿态，头略缩；转动头部时眼球先动（写"eyes move before head"） |
| 肢体 | 身体侧对目标（减小受击面）；手部靠近腰间/口袋；重心压低前倾 |
| 提示词 | vigilance, guarded expression, scanning narrowed eyes, defensive stance, coiled readiness |

### 24. 困惑（不解）
| 维度 | 细节 |
|------|------|
| 面部 | 眉毛不对称（一侧高一侧低）——真实困惑的标志 |
| 眉眼 | 单眉挑起；眼睛微眯或斜视 |
| 嘴部 | 嘴唇向一侧撇；或微张；或抿起 |
| 头部 | 歪头（15-30度）；或缓缓摇头（自我否定） |
| 肢体 | 手摸下巴/抓头发；耸肩；身体微微后退 |
| 提示词 | confusion, asymmetric raised brow, tilted head, squinting eyes, puzzled frown |

## 三、微表情动态序列（情绪转折怎么写）

> 写分镜提示词时，情绪不是静止的，用"初始态 → 过渡态 → 落点态"三段式。

| 转折 | 动态序列示例 |
|------|------------|
| 由笑转怒 | 嘴角笑意僵住 → 笑容迅速收敛 → 眉心下沉、眼神变冷 → 下颌收紧 |
| 由惊转喜 | 眼睛瞪大0.5s → 眉毛上挑 → 嘴角上扬、眼睛弯起 → 点头 |
| 由怒转哀 | 眉头松开 → 眼神从锐利变湿 → 嘴角下拉、嘴唇颤抖 → 低头 |
| 由哀转决绝 | 泪痕未干 → 深吸一口气 → 眼神从涣散聚焦 → 下巴微抬、嘴唇抿紧 |
| 由惧转勇 | 瞳孔收缩 → 喉结滚动（吞咽）→ 眉毛压低 → 咬紧牙关、下巴前伸 |

**提示词写法示例**：
```
transition: smile freezes -> fades -> brows lower, eyes turn cold -> jaw tightens
```

### 4.2 微表情生视频参数建议
- 特写镜头写微表情（脸部肌肉、眉眼、嘴角），中景写肢体语言，远景写整体姿态
- 微表情动作幅度要小：`subtle, barely perceptible`
- 动态序列加时间标注：`0-1s: ... 1-2s: ...`
- 强调克制感：`understated performance, restrained emotion`
- 反派/高智商角色优先使用"压抑型"微表情（条目8/16/18）
