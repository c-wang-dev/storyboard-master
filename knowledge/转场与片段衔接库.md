# 转场与片段衔接库

> 管「片段之间怎么接」。分镜决策引擎管单个片段内部怎么拍，本库管**片段 A 结束 → 片段 B 开始**的衔接选型。
> **输出位置**：模板 C「步骤 0 电影语法判断」的片段衔接检查 + 模板 D 的【衔接】与【首帧】字段（见 [[提示词模板]]）。
> **模型参数以 [[参数速查表]] 对应模型卡为准**，本库只存衔接逻辑与指令写法，不复制参数（防两处维护）。

## 一、衔接方式选型表（情节关系 → 衔接类型）

| 片段间情节关系 | 衔接类型 | 视觉效果 | 视频指令写法（按选定模型卡） |
|---------------|---------|---------|---------------------------|
| 动作连续（打斗连招、追逐延续） | 硬切卡点 | 节奏不断，张力延续 | A 段尾帧 = B 段首帧（同机位同景别），B 段 @Image1 引用该帧 |
| 情绪递进（对峙升温、悲伤加深） | 缓推/叠化 | 情绪过渡平滑 | B 段首帧取 A 段末人物状态，运镜用 slow push-in |
| 场景切换（换地点/换时间） | 空镜过渡 | 呼吸感，交代空间 | 插入 1 张场景空镜作 B 段首帧（establishing shot） |
| 场景切换（形状/动作呼应） | 匹配剪辑 | 高级感，视觉钩子 | A 段尾帧物体形状 ≈ B 段首帧物体形状（如圆月→刀环） |
| 时间跳跃（回忆/闪回/跳时段） | 闪白/黑场 | 明确的时空切割 | 黑场帧或过曝帧作 B 段首帧，配合色调突变描述 |
| 悬念转折（敌暗我明/反转前） | 甩镜转场 | 突发性，视线引导 | whip pan 收尾，B 段首帧接甩镜落点方向 |
| 节奏爆发（高潮连击段） | 快切卡点 | 肾上腺素 | 多段短镜头，每段首帧=上段尾帧动作顶点 |
| 情绪收尾（战后/离别余韵） | 空镜+缓拉 | 余韵留白 | 人物出画后接环境空镜，slow pull back |

**选型规则**：先判断片段间是上述哪种情节关系（一行一个），再取对应写法；拿不准时默认「硬切卡点 + 首尾帧一致」（最稳，模型执行成功率最高）。

## 三、15s 长片段拆分衔接规则（档位 15s 时适用）

```
15s 片段 = 3~5 个视频段（决策引擎 5.4 换算）
段内衔接：动作连续 → 硬切卡点（尾帧=下段首帧）
段间情绪转折：允许 1 次缓推/叠化，不超过 1 次（多了节奏拖）
跨场景：必须空镜过渡或匹配剪辑，禁止无过渡硬跳场景
```
