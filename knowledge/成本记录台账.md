# 成本记录台账

> **定位**：每一次真实 API 生成的花费与废片记录（旁挂文件，不参与生成检索）。**目的**：单条片子成本可算、废片率可查、六个模型性价比可比——企业采购第一问「单片成本多少」从这里拿数据。
> **记录纪律**：真实生成（点火/正式项目/评测重跑）必记；纯模拟输出（不调 API）不记。
> **建立**：2026-08-23，尚无记录。《月夜刀光》首次真实生成后开记。

- **阶段**取值：定妆照 / 三视图 / 场景图 / 分镜图 / 视频生成 / 评测重跑
- **结果**取值：✅采用 / ❌废片 / 🔁重生成
- 规格写清档位（如 2K 图 / 10s 视频），单价按当次账单实际填

## 二、废片原因分类（回写知识库的桥梁）

| 分类 | 含义 | 回写去向 |
|------|------|---------|
| A 提示词问题 | 描述不清/词组合不当导致画面错 | 优化对应知识库条目（走闸门 A） |
| B 模型能力边界 | 模型做不到，换模型才行 | 标注模型卡置信度与已知短板 |
| C 参数不当 | 尺寸/参考图数/运动强度用错 | 回填 [[参数速查表]] 对应模型卡 |
| D 一致性失败 | 角色脸漂/场景漂 | 回填 [[多帧一致性策略库]] |

> 每笔废片必须归因到 A/B/C/D 之一——废片数据是数据飞轮最贵的进料，不能白花。

## 三、月度统计模板（每月末填一行）

| 月份 | 总成本(¥) | 采用成本(¥) | 废片成本(¥) | 废片率 | A/B/C/D 占比 | 备注 |
|------|----------|-----------|-----------|-------|-------------|------|
| | | | | =废片次数/总次数 | | |

**衍生指标**：
- 单片成本 = 项目总成本 ÷ 成片时长（元/秒）
- 模型性价比 = 该模型采用率 ÷ 该模型平均单价（跨模型对比的依据）
- 首过成功率 = ✅直接采用次数 ÷ 总次数（衡量提示词质量的核心指标）

## 四、使用约定

1. 真实生成后**当场记**（事后补记必然漏）
2. 与 [[评测基准集]] 联动：评测重跑的成本记入「评测重跑」阶段，不混入项目成本
3. 月度统计触发治理审视：废片率 >30% 或某模型采用率 <50% → 列入闸门 C 体检重点
