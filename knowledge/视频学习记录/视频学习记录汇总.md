# 视频学习记录汇总

> 本页由 Dataview 自动汇总所有视频学习记录的结构化数据。新增记录时只需在文件头部添加 YAML frontmatter（`category` 字段必填：技术参数类 / 影视经典类），本页自动更新。

## 全量总览

```dataview
TABLE WITHOUT ID
  file.link AS "视频",
  category AS "分类",
  highlight AS "亮点",
  date AS "日期"
FROM "分镜知识库/视频学习记录"
WHERE type = "视频学习记录"
SORT date DESC
```

## 技术参数类（供参数速查表回填）

```dataview
TABLE WITHOUT ID
  file.link AS "视频",
  model AS "模型",
  param_type AS "涉及参数",
  confidence AS "置信度",
  date AS "日期"
FROM "分镜知识库/视频学习记录"
WHERE category = "技术参数类"
SORT date DESC
```

## 影视经典类（按亮点维度分组检索）

```dataview
TABLE WITHOUT ID
  file.link AS "片段",
  highlight AS "亮点维度",
  genre AS "题材",
  style AS "风格",
  date AS "日期"
FROM "分镜知识库/视频学习记录"
WHERE category = "影视经典类"
GROUP BY highlight AS "亮点维度"
SORT highlight ASC
```
