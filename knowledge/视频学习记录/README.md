# 视频学习记录

> 本目录存放视频投喂的归档。**投喂前必须分拣**——不同视频的优秀点并不全面，而是某一方面很突出，按两类分别归档：

## 分类规则（投喂必读）

| 分类 | 判断标准 | 学习目标 | 模板 |
|------|---------|---------|------|
| **A. 技术参数类** | 讲的是「用什么模型、什么参数」（新模型实测 / 参数对比 / 新技法） | 掌握最新参数，有效参数回填 [[参数速查表]] | [[_模板_技术参数类视频]] |
| **B. 影视经典类** | 讲的是「这段戏为什么好」（打戏 / 特效 / 配音 / 微表情 / 运镜 / 光影 / 节奏） | 提炼可复用创作技法，**一个片段只记一个最突出亮点** | [[_模板_影视经典类视频]] |

> ⚠️ 分拣铁律：**一视频一分类一亮点**。技术参数类视频不进影视经典库，反之亦然；影视经典类每个片段只深挖单一亮点维度，避免贪多记浅。
> 命名格式：`<片名>-<日期>.md`；模板文件以 `_模板_` 前缀开头，不参与汇总统计。

## 回填闸门（归档主库前必过）

**回填不是直接追加**——任何技法回填主库实例区前，必须过 [[知识库治理规则]] **闸门 A 写入三查**：

1. **查重**：同技法已有条目 → 合并出处，不新增条目
2. **仲裁**：与现有条目矛盾 → 置信度高者胜，败者标 deprecated 不删
3. **三要素**：必带「片名 / 日期 / 置信度」

容量红线（实例区软 20 / 硬 30 条，主库 600 行）与周期治理（每投 10 部全库体检）按 [[知识库治理规则]] 执行。
