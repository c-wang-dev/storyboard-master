# 权重控制配方库

> 控制「哪些元素被模型更重视」。**注意**：6 个选定模型里，只有 Flux 有显式权重概念（LoRA）；其余即梦/可灵/万相是自然语言模型，**没有 tag 权重语法**，靠「句序 + 强调词 + 位置」表达权重。

## 一、自然语言模型的强调方式（即梦 / 可灵 / 万相）

| 手段 | 效果 | 示例 |
|------|------|------|
| **放句首** | 权重最高，最被重视 | 把主体/风格词放最前面 |
| **具体化 > 形容词** | 具体词比泛化词更被准确执行 | "matted fleece texture" 优于 "soft" |
| **重复关键要素** | 重复 = 强调 | 主体在概述和分镜里各提一次 |
| **详略分配** | 篇幅 = 权重，想强调的多写 | 主体写 3 句，背景写 1 句 |

> 口诀：自然语言模型的"权重"就是**顺序和篇幅**，不是 `(word:1.3)`。

## 二、Flux 的 LoRA 权重

| 场景 | 权重 | 说明 |
|------|------|------|
| 角色 LoRA | 0.6-0.8 | 长期固定主角 |
| 风格 LoRA | 0.4-0.6 | 画风/氛围 |
| 多 LoRA 叠加 | 总强度 ≤1.0 | 超了互相污染 |

> Flux 无 tag 权重语法，靠句子结构和强调词表达权重；不用负面词。

## 三、权重调优实战流程（全模型通用）

1. **单变量原则**：一次只改一个变量，否则无法归因。
2. **二分法**：效果不足 → 强化（更靠前/更具体）；效果过强 → 弱化（后置/简化）。
3. **失败案例回写**（反馈闭环）：实战踩坑记录回写本库，标日期与置信度。
