# 提示词模板

> 分镜大师输出提示词包的**唯一标准格式**。四个板块（人物 / 场景 / 分镜图 / 视频）各有模板，智能体**必须按模板填空**，禁止临场自由发挥。
> 每个字段标注「← 取值来源」，智能体去对应知识库模块取料，保证术语准确、输出稳定、可复现。

## 〇、模型分流（先选模型，再填空，选后死锁）

**输入剧本时，先问使用者两个问题**（生图 + 生视频分别选，可不同）：

```
【生图模型】1. GPT-Image-2  2. Seedream 5.0 Pro  3. Flux
【生视频模型】1. Seedance 2.5  2. 可灵 3.0  3. 通义万相 2.7
```

> **死锁规则**：选定后，全程只按选定模型的模型卡输出，其他模型的字段/参数**不出现、不检索**。参数见 [[参数速查表]] 对应模型卡。

## 一、取料地图（字段 → 知识库模块）

| 字段 | 去哪个库取 |
|------|-----------|
| 镜头头（场次/内外景/日夜） | 剧本格式规范 |
| 档位 / 景别 / 角度 / 运镜 / 光影 / 节奏 / 图数 | **分镜决策引擎** |
| 角色描述 | 性格范式库·角色锚定卡 |
| 动作（打斗/兵器对攻帧） | 打斗动作库（含物理后果速查表） |
| 物理后果（所有含动作的帧） | **本模板·通用物理后果速查表**（打斗帧查打斗动作库，其余动作帧查本表） |
| 情绪 | 角色微表情库 |
| 光影 | 光影与色彩（+ 尾部实例归档区：片例验证词组合） |
| 风格 | 风格参考库（+ 尾部画风实例归档区） |

## 二、模板 A：人物角色（生图，按选定模型）

### A1 定妆照（先出这张，是全片锁脸源）

```
【角色名】定妆照 · 模型 [选定生图模型]

[年龄+体型+脸型+五官+发型发色+眼型]   ← 剧本 + 人物资产库
[服装+配饰+妆造]                      ← 人物资产库
[表情：锚定卡标志微表情（只取第一段，如"眉心常蹙"] ← 性格范式库·角色锚定卡
[均匀正面光、无遮挡]                   ← 定妆照固定要求

自然语言描述（英文优先——生图模型对英文理解更稳；中文外观描述需转英文，禁止中英混排）：
A front-facing character portrait, head and shoulders composition,
looking at viewer, [英文角色描述], even frontal lighting, clean background.
比例：3:4

负面词：GPT-Image-2 用 in-prompt 段 / Seedream 独立参数（deformed, bad anatomy, extra fingers）；Flux 不写
```

> **定妆照表情铁律**：只用锚定卡**标志性**微表情第一段（如"眉心常蹙"），**禁止**带情绪矩阵变体（"悲伤时…/愤怒时…"）——定妆照锁的是中性标准脸，变体表情会让锁脸失真。

### A2 三视图（定妆照之后，参考图驱动）

```
【角色名】三视图 · 模型 [选定生图模型]

[外观描述：与定妆照逐字一致，保证同款]
[中性站立表情]

自然语言描述：
A character turnaround reference of the same person, three views —
front, side, and back — identical face and outfit in all views,
standing straight, arms at sides, plain white background.

一致性：上传定妆照作参考图（GPT-Image-2/Seedream 参考图机制；Flux 图生图）
```

## 三、模板 B：场景（生图，按选定模型）

```
【场景名】场景设定图 · 模型 [选定生图模型]

[时代] [建筑风格+地形+室内外] [材质+关键物件+布局]
[光影：时间+天气+主光方向+色温] [情绪基调] [风格]

自然语言描述：
A wide establishing shot of [场景], [光线描述], [构图：单一氛围图 or 多角度],
cinematic composition. 比例：16:9

负面词：GPT-Image-2 用 in-prompt 段 / Seedream 独立参数；Flux 不写
```

> 多角度九宫格是「拼图任务」非「文生图任务」：逐角度生成再拼接。
>
> **场景图出图规则（防场景锚点漂移）**：
> 1. **按地点出一张**——同一地点（如屋脊）只出一张设定图，时间取主氛围（本剧主氛围=夜），**不按时间变体重复出图**（"屋脊·夜晚/屋脊·月夜"是同一种）
> 2. **时间同义归一**：夜晚/月夜/深夜/月光夜/黄昏后 → 统一记为「夜」；白昼/白天/正午/午后 → 「日」
> 3. 该场景所有分镜帧（不论机位/景别）共用这一张设定图作参考——多机位换景别不换场景图

## 四、模板 C：分镜图（三档 + 决策引擎驱动，最核心）

### 决策头（先生成，再填空）

```
【镜头头】场次X · 镜头N · 内/外景 · 地点 · 日/夜     ← 剧本格式规范
【模型】[选定生图模型]                               ← 模型分流·死锁
【档位】[5s / 10s / 15s]                            ← 决策引擎·5.1
【档位确认】使用者已确认 ✓
【决策】景别[ ] 角度[ ] 运镜[ ] 光影[ ] 节奏[ ]       ← 决策引擎·五张表
【图数】本片段 [ ] 张                                ← 决策引擎·5.2
```

### 提示词块（自然语言，逐张关键帧各写一条）

```
【关键帧 1 / N】[景别+角度]
[主体 + 动作 + 情绪 + 景别 + 角度 + 运镜 + 光影 + 物理后果 + 表演微表情] 的自然语言长句
负面词写法（按选定生图模型）：
- GPT-Image-2：提示词正文**另起一行**写 negative prompt: deformed, bad anatomy, extra fingers（in-prompt 段，无独立参数）
- Seedream 5.0 Pro：独立负面词参数（精简 3-6 条）
- Flux：不写负面词
```

### 一致性建议 + 参数块

```
【一致性建议】← 多帧一致性策略库（按选定模型）
- 参考图1：角色定妆照（同一张贯穿全分镜，锁脸源）
- 参考图2：场景设定图（同场景多机位贯穿，锁场景全貌）
- [GPT-Image-2/Seedream] 上传定妆照+场景图作参考图 / [Flux] 角色 LoRA 0.6
【参数块】← 参数速查表对应模型卡
[选定模型] · [该模型卡的参数]
```

### 完整示例（对白/情绪戏 · 假定选定 Seedream 5.0 Pro）

```
【镜头头】场次12 · 镜头3 · 内景 · 反派书房 · 夜
【模型】Seedream 5.0 Pro
【档位】5s（单一反应）【档位确认】✓
【决策】景别=近景 角度=平视 运镜=固定 光影=低调冷色 节奏=慢
【图数】1 张

【关键帧 1/1】近景·平视
A close-up of a stone-faced middle-aged man in a dark robe,
unreadable gaze, subtle cold smile, low-key lighting, cold blue tone,
rim light, static camera, dark fantasy, cinematic still. 比例 16:9

【一致性建议】参考图：锚定卡#3 定妆照（上传作参考图）
【参数块】Seedream 5.0 Pro · 尺寸 2K · 比例 16:9 · 负面词精简
```

### 附：电影质感词映射（写进提示词风格，通用）

| 实拍质感 | 自然语言词 |
|----------|-----------|
| 院线大片感 | cinematic lighting, anamorphic lens flare, film grain |
| 浅景深人像 | shallow depth of field, 85mm compression, creamy bokeh |
| 暖黄怀旧 | warm Kodak tone, golden hour, nostalgic film look |
| 冷峻青灰 | cool teal-grey grade, muted desaturated palette |
| 高反差黑白 | high-contrast monochrome, grainy black and white |

### 附：动作物理后果速查表（通用）

> **铁律（蒸馏自 director-skills Motion Physics）**：所有**含动作**的帧（行走/奔跑/转身/起身坐下/持物/拔收刀/跃起落地/挥手/受风/上楼/开关门/坠泪……）提示词**必须带 1–2 项物理后果**（重量 / 摩擦 / 环境反应），否则画面"飘"。纯静态定格（无动作特写/空镜）可豁免。
> **分工**：打斗/兵器对攻动作（挥砍/拳击/踢击/格挡/受击扑击/倒地）→ 查 [[打斗动作库]] 物理后果速查表；日常与过渡动作 → 查下表。

| 动作类型 | 物理后果（重量 / 摩擦 / 环境反应） |
|---------|------|
| 行走 / 缓步 / 踱步 | 衣摆·斗篷随步伐滞后摆动；鞋底与地面轻响；踏过碎石碎屑弹动 |
| 奔跑 / 疾行 | 衣袂向后紧贴；地面尘土被脚步带起；肩部随呼吸起伏 |
| 转身 / 回头 / 环视 | 发梢·衣袖滞后甩动；披风划出弧线；脚下尘土被旋起 |
| 起身 / 坐下 / 倚靠 | 椅面/地面受力轻响；衣料下坠贴回身体；桌面物件轻震 |
| 持物 / 端起 / 放下 | 指节因用力泛白；器皿内液体晃动；手腕承重微颤 |
| 拔刀 / 收刀（兵器过渡，非对攻） | 出鞘金属摩擦声·寒光；入鞘金属卡顿"咔哒"；手腕承重微颤 |
| 跃起 / 翻越 / 落地 | 起跳前地面下压借力；衣袂上飘滞后；落地尘土溅开·膝盖缓冲 |
| 挥手 / 抬手 / 摆手 | 袖口滑落露出手腕；衣袖滞后跟随 |
| 受风 / 立于风中 | 发丝与衣摆同向持续飘动；披风绷紧作响；沙尘扑面眯眼 |
| 上楼 / 台阶 / 门槛 | 木阶受重吱呀；扶手掌心摩擦；裙摆扫过台阶边缘 |
| 开门 / 推门 / 关门 | 门轴吱呀；门板带起气流吹动烛火/纸张 |
| 坠泪 / 情绪外溢 | 泪珠受重力沿脸颊滑落；喉结滚动吞咽 |

## 五、模板 D：视频生成（按选定生视频模型）

```
视频 · [档位]片段 · 模型 [选定生视频模型]

【首帧】= 对应分镜图 或 定妆照（图生视频）
【动作】自然语言描述运动，不重述画面（见参数速查表模型卡的提示词公式）
【时长】Seedance 4-30s / 可灵 5·10·15s / 万相按时间戳
【衔接】← 转场与片段衔接库（按片段间情节关系选型；默认硬切卡点+首尾帧一致）
【音频】← 音频指令配方库（按片段类型选配方，写法用选定模型卡的音频字段，台词逐字用剧本原文）
【参数】见参数速查表对应模型卡
```
