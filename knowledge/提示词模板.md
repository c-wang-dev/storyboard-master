# 提示词模板

> 分镜大师输出提示词包的**唯一标准格式**。四个板块（人物 / 场景 / 分镜图 / 视频）各有模板，智能体**必须按模板填空**，禁止临场自由发挥。
> 每个字段标注「← 取值来源」，智能体去对应知识库模块取料，保证术语准确、输出稳定、可复现。

## 〇、模型分流（先选模型，再填空，选后死锁）

**输入剧本时，先问使用者两个问题**（生图 + 生视频分别选，可不同）：

```
【生图模型】1. 即梦 image2  2. Seedream 5.0 Pro  3. Flux
【生视频模型】1. Seedance 2.5  2. 可灵 3.0  3. 通义万相 2.7
```

> **死锁规则**：选定后，全程只按选定模型的模型卡输出，其他模型的字段/参数**不出现、不检索**。参数见 [[参数速查表]] 对应模型卡。

## 一、取料地图（字段 → 知识库模块）

| 字段 | 去哪个库取 |
|------|-----------|
| 镜头头（场次/内外景/日夜） | 剧本格式规范 |
| 档位 / 景别 / 角度 / 运镜 / 光影 / 节奏 / 图数 | **分镜决策引擎** |
| 角色描述 | 性格范式库·角色锚定卡 |
| 动作 | 打斗动作库 |
| 情绪 | 角色微表情库 |
| 光影 | 光影与色彩（+ 尾部实例归档区：片例验证词组合） |
| 风格 | 风格参考库（+ 尾部画风实例归档区） |
| 运镜英文词 | 镜头语言（+ 尾部实例归档区） |
| 一致性 | 多帧一致性策略库 |
| 参数 | 参数速查表 / 场景配方库 |
| 演技复刻（中性转写） | 明星演技样本库 |
| 衔接（片段间） | 转场与片段衔接库 |
| 音频（视频提示词） | 音频指令配方库 |
| 负面词 | 分镜决策引擎·全局负面清单 A 层 + 锚定卡禁止表演（合并；Flux 不写） |

## 二、模板 A：人物角色（生图，按选定模型）

### A1 定妆照（先出这张，是全片锁脸源）

```
【角色名】定妆照 · 模型 [选定生图模型]

[年龄+体型+脸型+五官+发型发色+眼型]   ← 剧本 + 人物资产库
[服装+配饰+妆造]                      ← 人物资产库
[表情：性格范式标志微表情]             ← 性格范式库·角色锚定卡
[均匀正面光、无遮挡]                   ← 定妆照固定要求

自然语言描述（中英文均可，主体放句首）：
A front-facing character portrait, head and shoulders composition,
looking at viewer, [角色描述], even frontal lighting, clean background.
比例：3:4

负面词：仅即梦/Seedream 写（deformed, bad anatomy, extra fingers）；Flux 不写
```

### A2 三视图（定妆照之后，参考图驱动）

```
【角色名】三视图 · 模型 [选定生图模型]

[外观描述：与定妆照逐字一致，保证同款]
[中性站立表情]

自然语言描述：
A character turnaround reference of the same person, three views —
front, side, and back — identical face and outfit in all views,
standing straight, arms at sides, plain white background.

一致性：上传定妆照作参考图（即梦/Seedream 参考图机制；Flux 图生图）
```

## 三、模板 B：场景（生图，按选定模型）

```
【场景名】场景设定图 · 模型 [选定生图模型]

[时代] [建筑风格+地形+室内外] [材质+关键物件+布局]
[光影：时间+天气+主光方向+色温] [情绪基调] [风格]

自然语言描述：
A wide establishing shot of [场景], [光线描述], [构图：单一氛围图 or 多角度],
cinematic composition. 比例：16:9

负面词：仅即梦/Seedream 写；Flux 不写
```

> 多角度九宫格是「拼图任务」非「文生图任务」：逐角度生成再拼接。

## 四、模板 C：分镜图（三档 + 决策引擎驱动，最核心）

### 决策头（先生成，再填空）

```
【镜头头】场次X · 镜头N · 内/外景 · 地点 · 日/夜     ← 剧本格式规范
【模型】[选定生图模型]                               ← 模型分流·死锁
【档位】[5s / 10s / 15s]                            ← 决策引擎·5.1
【档位确认】使用者已确认 ✓
【决策】景别[ ] 角度[ ] 运镜[ ] 光影[ ] 节奏[ ]       ← 决策引擎·五张表
【图数】本片段 [ ] 张                                ← 决策引擎·5.2
```

### 提示词块（自然语言，逐张关键帧各写一条）

```
【关键帧 1 / N】[景别+角度]
[主体 + 动作 + 情绪 + 景别 + 角度 + 运镜 + 光影] 的自然语言长句
（主体放句首；即梦/Seedream 可写负面词，Flux 不写）
```

### 一致性建议 + 参数块

```
【一致性建议】← 多帧一致性策略库（按选定模型）
- 参考图：角色定妆照（同一张贯穿全分镜）
- [即梦/Seedream] 上传参考图 / [Flux] 角色 LoRA 0.6
【参数块】← 参数速查表对应模型卡
[选定模型] · [该模型卡的参数]
```

### 完整示例（对白/情绪戏 · 假定选定 Seedream 5.0 Pro）

```
【镜头头】场次12 · 镜头3 · 内景 · 反派书房 · 夜
【模型】Seedream 5.0 Pro
【档位】5s（单一反应）【档位确认】✓
【决策】景别=近景 角度=平视 运镜=固定 光影=低调冷色 节奏=慢
【图数】1 张

【关键帧 1/1】近景·平视
A close-up of a stone-faced middle-aged man in a dark robe,
unreadable gaze, subtle cold smile, low-key lighting, cold blue tone,
rim light, static camera, dark fantasy, cinematic still. 比例 16:9

【一致性建议】参考图：锚定卡#3 定妆照（上传作参考图）
【参数块】Seedream 5.0 Pro · 尺寸 2K · 比例 16:9 · 负面词精简
```

### 附：电影质感词映射（写进提示词风格，通用）

| 实拍质感 | 自然语言词 |
|----------|-----------|

| 浅景深人像 | shallow depth of field, 85mm compression, creamy bokeh |

## 五、模板 D：视频生成（按选定生视频模型）

```
视频 · [档位]片段 · 模型 [选定生视频模型]

【首帧】= 对应分镜图 或 定妆照（图生视频）
【动作】自然语言描述运动，不重述画面（见参数速查表模型卡的提示词公式）
【时长】Seedance 4-30s / 可灵 5·10·15s / 万相按时间戳
【衔接】← 转场与片段衔接库（按片段间情节关系选型；默认硬切卡点+首尾帧一致）
【音频】← 音频指令配方库（按片段类型选配方，写法用选定模型卡的音频字段，台词逐字用剧本原文）
【参数】见参数速查表对应模型卡
```
