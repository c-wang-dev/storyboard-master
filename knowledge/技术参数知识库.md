# 技术参数知识库

> 本模块是分镜知识库的「技术参数层」。分镜大师作为「大脑」输出提示词包时，附带的模型参数建议全部来自本模块。
> 定位：**不教怎么操作生图/生视频软件**（那是「手」的执行层），而是让分镜大师输出的提示词包里自带「用什么参数画得稳」的建议，下游工具拿到即可用。
>
> **数据保鲜规则（重要）**：每条参数必须带三要素 —— 适用模型版本 / 实测日期 / 置信度。
> 置信度图标：📖 官方一手 > ✅ 社区实测验证 > 🧪 单次测试/传闻。
> 模型更新导致参数过时时：**不删旧值**，标 `deprecated` + 写替代方案（与角色锚定卡「不硬切、弹性使用」同一哲学）。

## 与「大脑-手」架构的关系

```
分镜大师（大脑）──输出提示词包──→ 生图/生视频软件（手）──→ 画面
  │                                    │
  └── 从本模块取「参数建议」──→ 附带在提示词包里
```

分镜大师不做三件事：不跑模型、不调 UI、不按生成按钮。它做的唯一技术性工作就是：**根据下游工具的底模类型，从本模块取正确的参数建议，写进提示词包**。

## 参数保鲜（持续优化机制）

本模块不是一次性文档，靠四条输入线保鲜：

1. **视频投喂（技术参数类）**：用户投喂的新模型实测视频 → 归档到 [[视频学习记录/README]] 技术参数类 → 有效参数回填本模块
2. **官方文档 / Changelog**：模型发布方更新时同步参数（一手信息，优先级最高）
3. **社区实测**：Civitai 模型页作者推荐、Reddit / B站 UP 主实测配方
4. **实战反馈闭环**：分镜大师输出的参数 → 实际生成效果差 → 回传修正 → 更新配方

**入口约定**：先模型分流（死锁到选定模型卡），再按需查子模块：
`参数速查表`（取模型卡基线）→ `多帧一致性策略库`（锁角色）→ `场景配方库`（套场景配方）
