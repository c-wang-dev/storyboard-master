# 性格范式库

> **用途**：解决"不同演员演不出同一种情绪"导致的表演割裂。每个角色先锁定一个**性格范式**，再从这个范式内部的"情绪 × 程度"矩阵里取微表情，全片统一，绝不跨范式混搭。
> **核心原则**：性格是唯一主维度（决定"怎么演"）；身份、正反派是**标签**（决定服饰/动作幅度，不影响微表情内核），用 `#标签` 标注在条目末尾，不单独分层。
> **程度档位**：轻（微露）→ 中（明显）→ 重（强烈）→ 爆发（失控），共四档。**弹性使用**——怒/悲/喜用满四档，惊讶/厌恶两到三档即可，不必强凑。

---

## 使用方式

### 学习归档（喂样片时）
1. 看样片某个角色，先判定它的**性格范式**（阳奉阴违？直来直去？背地阴狠？）
2. 把观察到的微表情细节，追加到对应条目的「实例归档」区，打上身份/正反派标签
3. 不同片子的同性格角色，归到**同一条目** → 形成该性格的样本池

### 生成检索（写新剧本时）
```
角色 → 锁定性格范式 → (用标签过滤身份/正反派变体)
     → 该范式内"情绪 × 程度"矩阵 → 出微表情提示词
```
一个角色的所有情绪都从**同一条目**取，表演逻辑全程统一。

### 角色锚定卡（生成前必做）
选定性格范式后，为角色生成一张**锚定卡**，全片常驻、不回库检索：

```
【角色锚定卡】角色名 — 性格范式
- 标志微表情：...（1-2个，来自本条目）
- 情绪矩阵：...（从本条目复制）
- 禁止表演：...（负面清单，来自本条目）
```

---

## 程度档位说明

| 档位 | 状态 | 表现 |
|------|------|------|
| 轻 | 微露 | 仅眼神/微表情，收着，观众需细看才能察觉 |
| 中 | 明显 | 表情 + 呼吸变化，正常对话能看出 |
| 重 | 强烈 | 表情 + 肢体 + 语速变化，情绪外显 |
| 爆发 | 失控 | 极限状态（咆哮/崩溃/痛哭），打破角色常态 |

## 一、反派系性格

### 1. 阳奉阴违型（笑面虎）

- **核心特征**：当面奉承讨好，背后使绊子。永远带笑，笑容与真实意图完全相反。
- **标志性微表情**：嘴笑眼冷（眼轮匝肌不参与，眼神无笑意）；说话时眼神先扫视四周再落回对方；点头幅度大而频繁，显得过分热情。
- **情绪 × 程度**：
  - 开心（假）：礼貌堆笑(轻) → 谄媚弯腰(中) → 夸张奉承(重) → 无爆发档（此型不外放）
  - 怒（被戳穿）：笑意僵在脸上(轻) → 眼神骤冷、笑容褪去(中) → 冷声警告、下颌绷紧(重) → 极罕见爆发，一旦爆发即撕破脸(爆发)
  - 悲：不真悲，只表演痛心(轻) → 假抹泪、偷瞄对方反应(中)
  - 惧：堆笑讨好、点头如捣蒜(轻) → 眼神游移、冒汗强撑(中) → 语无伦次、笑容抽搐(重)
- **英文提示词**：`insincere smile, smiling mouth cold eyes, sycophantic nod, shifty glance, false warmth`
- **变体标签**：`#反派叛徒` `#正派卧底` `#商人` `#幕僚` `#弄臣`
- **禁止表演**：真诚大笑、坦荡对视、情绪直接外放

### 2. 背地阴狠型（笑里藏刀）

- **核心特征**：表面温和有礼，暗地里下手最狠。笑是伪装，狠是底色。
- **标志性微表情**：嘴角微扬但眼底无光；说话轻声慢语；眼神在对方视线移开瞬间变得冰冷；侧脸/半侧脸时露出真实狠意。
- **情绪 × 程度**：
  - 开心（假）：温和微笑(轻) → 慈眉善目(中) → 关怀备至的表演(重) → 无爆发档
  - 怒（暗涌）：笑容不变、指节泛白(轻) → 眼底结冰、语速放慢(中) → 平静说出狠话(重) → 极罕见，一旦爆发即致命(爆发)
  - 悲：不流泪，只是目光变深(轻) → 短暂闭眼压抑(中)
  - 惧：几乎不惧，只有"被看穿"的瞬间瞳孔微缩(轻)
- **英文提示词**：`gentle smile concealing menace, cold glint in eyes, soft-spoken threat, barely visible rage, repressed lethality`
- **变体标签**：`#反派叛徒` `#笑面虎` `#权臣` `#军师`
- **禁止表演**：怒目圆睁、青筋暴起、情绪写在脸上
- **实例归档**：（学习时追加）
- **挂靠样本卡**：[[明星演技样本库]] § （待绑定）

### 3. 阴鸷深沉型（冷面谋略）

- **核心特征**：不动声色，深不可测，情绪极少外露，让人猜不透。
- **标志性微表情**：面无表情或眉头微蹙；眼神长时间锁定对方不闪躲；单侧挑眉表示玩味；嘴角几乎不动，说话时下颌动作极小。
- **情绪 × 程度**：
  - 开心：不笑，仅眼神稍缓(轻) → 嘴角极轻微上扬(中) → 冷笑(重)
  - 怒：眉眼下压、眼神变重(轻) → 下颌紧绷、语气转冷(中) → 单侧挑眉+冷笑(重) → 极罕见爆发，一旦爆发摧枯拉朽(爆发)
  - 悲：眼神下移、沉默(轻) → 闭目、喉结微动(中)
  - 惧：几乎不惧，只有"局面失控"时眼神第一次闪动(轻)
- **英文提示词**：`stone-faced, unreadable gaze, subtle raised eyebrow, barely perceptible smile, cold intensity, controlled menace`
- **变体标签**：`#反派领袖` `#谋略家` `#幕后黑手`
- **禁止表演**：夸张表情、急促语速、慌乱失措
- **实例归档**：（学习时追加）
- **挂靠样本卡**：[[明星演技样本库]] § （待绑定）

### 4. 暴戾外放型（狂躁）

- **核心特征**：情绪直接爆发，攻击性强，靠震慑压人，不藏不装。
- **标志性微表情**：眉心拧紧、青筋暴起、眼睛瞪大或充血；咆哮时颈筋暴起；呼吸粗重，鼻翼翕动。
- **情绪 × 程度**：
  - 开心：咧开嘴大笑、拍桌(轻) → 狂笑不止(中) → 兴奋到呼吸急促(重)
  - 怒：皱眉、鼻息变重(轻) → 瞪眼、声音拔高(中) → 咆哮、青筋暴起(重) → 彻底失控、摔砸殴打(爆发)
  - 悲：不常见，多以"怒"替代悲伤(轻)
  - 惧：几乎不惧，以更强攻击性掩饰(轻)
- **英文提示词**：`bulging veins, bloodshot glaring eyes, clenched jaw, snarling, heavy breathing, explosive rage`
- **变体标签**：`#反派打手` `#暴君` `#狂战士` `#正派莽夫`
- **禁止表演**：隐忍克制、阴冷算计、温和有礼
- **实例归档**：（学习时追加）
- **挂靠样本卡**：[[明星演技样本库]] § （待绑定）

### 5. 骄纵轻浮型（得意忘形）

- **核心特征**：轻佻傲慢，喜欢炫耀，眼高于顶，得势便猖狂。
- **标志性微表情**：下巴微抬、俯视眼神；说话时单边嘴角上扬、语气上扬拖长音；频繁甩头/撩发/抖腿等小动作。
- **情绪 × 程度**：
  - 开心：得意的笑、下巴高抬(轻) → 炫耀式大笑(中) → 手舞足蹈、目中无人(重)
  - 怒：不屑撇嘴(轻) → 尖声斥责、翻白眼(中) → 摔东西、歇斯底里(重) → 破口大骂、仪态尽失(爆发)
  - 悲：不真悲，装可怜博关注(轻)
  - 惧：色厉内荏、声音发抖(轻) → 抱头躲避、惊慌失措(中)
- **英文提示词**：`haughty chin-up, condescending smirk, smug grin, eye-rolling, flippant swagger, pretentious flamboyance`
- **变体标签**：`#反派二世祖` `#纨绔` `#暴发户` `#丑角`
- **禁止表演**：沉稳克制、眼神坚定、不怒自威

## 二、正派系性格

### 6. 隐忍坚毅型

- **核心特征**：压抑悲愤、隐忍负重，情绪憋在心里，眼神坚定但有痛。
- **标志性微表情**：眉心常蹙、眼神坚定向下或直视；悲伤时眼睑半垂、嘴角极轻微颤抖；愤怒时下颌绷紧、拳头攥紧但不出声。
- **情绪 × 程度**：
  - 开心：难得的真笑，眼角微弯(轻) → 释然的笑、肩膀放松(中)
  - 怒：眼神变硬、抿嘴(轻) → 下颌绷紧、拳头攥紧(中) → 声音发颤的质问(重) → 极罕见爆发，一旦爆发痛彻心扉(爆发)
  - 悲：眼睑半垂、嘴角微颤(轻) → 眼角含泪强忍(中) → 无声落泪(重) → 崩溃痛哭(爆发)
  - 惧：呼吸微乱、瞳孔微缩(轻) → 强撑不退、身体绷紧(中)
- **英文提示词**：`repressed grief, resolute gaze, clenched jaw, trembling lip, silent tears, stoic endurance`
- **变体标签**：`#正派主角` `#复仇者` `#忠臣` `#苦情`
- **禁止表演**：轻浮嬉笑、夸张咆哮、轻易落泪

### 7. 豪爽直率型

- **核心特征**：直来直去，喜怒形于色，性情中人，不藏心机。
- **标志性微表情**：说话时眉飞色舞、手势大开大合；大笑时眼睛完全眯起、露出整排牙；生气时直接瞪眼、拍桌。
- **情绪 × 程度**：
  - 开心：咧嘴大笑、拍肩(轻) → 仰天大笑、声如洪钟(中) → 笑得前仰后合(重)
  - 怒：皱眉瞪眼、声音变大(轻) → 拍桌而起、怒目(中) → 破口大骂(重) → 掀桌动手(爆发)
  - 悲：不轻易悲，悲时无声、眼眶发红(轻) → 捶胸顿足(中) → 嚎啕大哭(重)
  - 惧：几乎不惧，越怕越冲(轻)
- **英文提示词**：`hearty laugh, expressive brows, wide open gestures, straightforward gaze, unguarded emotion`
- **变体标签**：`#正派兄弟` `#侠客` `#莽夫` `#武将`
- **禁止表演**：阴冷算计、假笑奉承、欲言又止

### 8. 温润儒雅型

- **核心特征**：克制温和，君子之风，情绪收放有度，泰山崩于前而色不变。
- **标志性微表情**：眼神平和、目光如水；微笑时嘴角轻轻上扬、眼含暖意；愤怒时只是眼神微凉、语气微沉，不改从容。
- **情绪 × 程度**：
  - 开心：浅笑、眼神温柔(轻) → 温和的笑、点头赞许(中)
  - 怒：笑意收敛、眼神微凉(轻) → 语气转沉、神情肃穆(中) → 平静说重话(重) → 极罕见，一旦爆发摄人心魄(爆发)
  - 悲：目光低垂、沉默(轻) → 眼眶微红、强作镇定(中) → 无声垂泪(重)
  - 惧：几乎不惧，最多眉心微动(轻)
- **英文提示词**：`gentle warm gaze, composed countenance, restrained smile, quiet dignity, serene poise`
- **变体标签**：`#正派君子` `#儒将` `#谋士` `#师尊`
- **禁止表演**：失态咆哮、张狂炫耀、喜怒无常

## 附：英文提示词使用规范

1. **锚定卡优先**：生成分镜时，从角色锚定卡取英文提示词，不要临时从其他性格条目挪用。
2. **负向词同步**：把该性格的「禁止表演」转成 negative prompt（如 `no exaggerated grimace, no flippant smirk, no flailing gestures`）。
3. **档位映射**：轻/中/重/爆发 → 提示词分别用 `subtle / apparent / intense / extreme` 修饰表情强度。
4. **跨范式转变**：只有剧情动机（黑化/爆发/崩溃）才允许切换范式，且必须单镜头内完成，禁止无动机跳变。
