# 明星演技样本库

> 定位：**人格化的表演风格层**——样本提供"怎么演"（行为模式、节奏、气场），与 [[性格范式库]]（角色"是谁"）、[[角色微表情库]]（通用"肌肉层"）构成三层表演体系。
>
> 复刻边界：**只复刻演技、神态、动作，绝不复刻声音和长相。**

## 🔴 红线与输出闸门（最高优先级规则）

1. **输出脱敏**：任何提示词中**绝不出现**样本真名、艺名、代称、相似表述（如"像XX的演员"）。库内编号（角色N）只作内部溯源。
2. **不复刻载体**：声音特征（音色、口音、台词腔）和面部特征不进入样本卡，也不进入任何输出。
3. **抽象层建设**：样本卡只存**行为模式的中性描述**（节奏、停顿、体态、气场、习惯动作），这些是演技本体，可学习、可输出。
4. 理由：肖像权/人格权（民法典禁止信息技术伪造他人肖像，声音受同等保护）+ 下游平台对名人名的拦截——脱敏输出反而是**唯一可被执行**的方案。

## 脱敏四步流水线（投喂样本的标准流程）

```
① 拆解：看样本视频，拆出可观察的行为要素（停顿习惯/体态/眼神节奏/手势/气场策略）
② 抽象：剥离具体人脸声音，只留行为模式（"开口前停半秒"而非"某演员的脸"）
③ 中性转写：翻译成可执行的画面描述词（威压式凝视、声线低沉沉稳、语速慢而笃定）
④ 挂范式条目：与 [[性格范式库]] 条目关联；若无范式可挂 → 记录为"范式盲区"，提议扩范式库
```

## 样本卡结构

```markdown
### {编号}（{内部溯源名，仅库内可见}）
- **表演基底**：{2-3 句行为模式总述：气场类型、节奏特征、能量水平}
- **神态特征**：{眼神运用、面部控制习惯——中性描述}
- **动作与体态**：{站姿坐姿、手势系统、移动方式}
- **节奏特征**：{说话/反应的停顿规律、快慢拍型}
- **标志性习惯**：{1-2 个最具辨识度的行为模式} ⚠️ 限用于关键镜头（特写、情绪转折）
- **挂靠范式**：[[性格范式库]] {条目名} / 或「范式盲区：{说明}」
- **远景降级策略**：{神态不可见时，用哪些体态/动作特征维持辨识度}
- **样本来源**：{作品+场景，供拆解溯源}（仅库内记录）
```

## 样本卡示例（脱敏演示，非真实样本）

> 真实样本卡存于私有库（含内部溯源编号，不公开）。以下两条为虚构示例，仅演示样本卡的内容结构。

### 示例A：威压型内敛表演（虚构演示）
- **表演基底**：权威感靠凝视和停顿建立，不靠音量；能量向内收而非向外放
- **神态特征**：审视式凝视；情绪波动几乎不上脸，只在眼神深处变化
- **动作与体态**：脊背挺直、肩部稳定；手势少而精准、慢半拍
- **节奏特征**：开口前停顿半秒；语速慢、句尾笃定不飘
- **标志性习惯**：①开口前停顿+凝视 ②听到荒谬言论时的极短闭眼 ⚠️ 限用于关键镜头
- **挂靠范式**：[[性格范式库]] 阴鸷深沉
- **远景降级策略**：挺直脊背+稳定静止姿态

### 示例B：松弛型外放表演（虚构演示）
- **表演基底**：举重若轻，用"不使劲"制造真实感；小人物的智慧感来自"先怂半拍、后亮底牌"
- **神态特征**：眼神灵活、笑意不达眼底；尴尬时快速游移再回位
- **动作与体态**：体态松弛微含胸；手势生活化、幅度小频率高
- **节奏特征**：语速偏快带拖音；严肃台词用轻描淡写的语气说
- **标志性习惯**：①轻描淡写说重话 ②尴尬时眼神游移 ⚠️ 限用于关键镜头
- **挂靠范式**：「范式盲区」→ 建议新增"圆融世故/小人物智慧"范式条目
- **远景降级策略**：松弛体态与他人紧张体态的对比

## 绑定机制（与项目角色绑定表联动）

使用者一句话绑定（如"角色1 演剧本里的张三"）→ 智能体写入该项目的《项目角色绑定表》→ 全剧解析该角色镜头时自动应用样本基底 → 输出提示词时只出现中性表演描述，**不出现样本编号与真名**。

四条运行规则：
1. **剧本性格 > 样本习惯**：样本提供"怎么演"，剧本提供"演什么人"；冲突明显时向使用者提示
2. **一样本一角色**：同一部剧内一个样本只绑一个角色（防表演同质化）
3. **标志习惯限用**：标志性动作只在关键镜头（特写、情绪转折）使用，防滑稽模仿感
4. **远景降级**：神态不可见的景别，自动切换到体态/动作特征维持辨识度

绑定表模板见 [[项目角色绑定表_模板]]。
