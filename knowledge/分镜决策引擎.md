# 分镜决策引擎

> 分镜大师「大脑」的核心决策层。解决一个根本问题：**大模型「知道」景别光影，但不会「按规则决策」**——拿到剧本只会凭感觉给建议。
> 本引擎把「剧本片段 → 视听参数」变成**硬性映射规则**，保证同样输入永远得到同样输出（确定性、可解释、可回写修正）。

## 一、工作流

```
剧本片段（5s / 10s / 15s 三档，先选档）
  → 特征提取层（分析 6 个决策输入）
  → 五张决策表（条件 → 视听参数）
  → 仲裁层（冲突时按优先级让步）
  → 视听参数包（景别 · 角度 · 运镜 · 光影 · 节奏）
```

## 二、特征提取层（6 个决策输入）

| 输入 | 分析什么 |
|------|---------|
| 内容类型 | 对白 / 动作 / 情绪 / 环境 / 悬念 / 揭示 |
| 信息焦点 | 这段要传达什么（环境 / 关系 / 动作 / 情绪 / 细节）|
| 情绪强度 | 平静 / 紧张 / 爆发 |
| 权力关系 | 谁强谁弱、威胁方向 |
| 空间关系 | 室内外、距离、大小 |
| 节奏倾向 | 快 / 慢 |

## 三、五张决策表

### 表 1：景别表（信息焦点 → 景别）

| 信息焦点 | 决策景别 |
|---------|:---:|
| 环境 / 世界观 / 位置 | 远景 / 大远景 |
| 人物与环境关系 / 动作幅度 | 全景 |
| 双人关系 / 身体语言 / 对白 | 中景 |
| 情绪转折 / 关键反应 | 近景 / 特写 |
| 眼神 / 手部 / 关键道具 | 大特写 |

### 表 2：角度表（权力关系 → 角度）

| 权力关系 | 决策角度 | 效果 |
|---------|:---:|------|
| 强势 / 威压 | 仰拍 | 放大压迫 |
| 弱势 / 被支配 | 俯拍 | 放大渺小 |
| 对等 / 客观叙述 | 平视 | 中性不引导 |
| 代入角色主观 | POV | 观众成为角色 |
| 世界失衡 / 心理不安 | 荷兰角 | 倾斜即失序 |

### 表 3：运镜表（运动目的 → 运镜）

| 运动目的 | 决策运镜 | 效果 |
|---------|:---:|------|
| 主体移动 / 追击 | 跟 / 移 | 主体保持画面重心 |
| 悬念揭晓 / 视线聚焦 | 推近 | 空间压缩 |
| 段落结束 / 离开 | 拉远 | 空间释放 |
| 建立场景内关系 | 摇 | 揭示空间联系 |
| 不安 / 纪实 / 慌乱 | 手持 | 画面抖动即情绪抖动 |
| 对峙 / 压抑 | 固定机位 | 静止即剑拔弩张 |

### 表 4：光影表（情绪基调 → 光影）

| 情绪基调 | 决策光影 | 效果 |
|---------|:---:|------|
| 压抑 / 危险 / 绝望 | 低调照明 + 冷色 | 阴影吞噬 |
| 希望 / 安全 / 胜利 | 高调照明 + 暖色 | 明亮温暖 |
| 神秘 / 悬念 / 未知 | 硬侧光（半明半暗）| 藏一半露一半 |
| 悲怆 / 牺牲 / 沉重 | 逆光剪影 | 轮廓化留情绪 |
| 威胁 / 诡异 | 顶光 / 底光 | 面部阴影变形 |

### 表 5：节奏表（情绪强度 × 信息密度 → 节奏）

| 情绪强度 / 内容 | 决策节奏 |
|---------|:---:|
| 对白 / 情绪戏 | 镜头 3~5 秒，少切，留表演气口 |
| 动作 / 冲突 / 追击 | 镜头 1~2 秒，快切，动作匹配 |
| 悬念 / 揭示 | 缓慢推近 + 停帧，蓄力 |
| 高潮爆发 | 快速剪辑 + 特写堆叠 |

## 四、仲裁层（冲突优先级，写死）

五维决策可能冲突（如「强势反派表白」：权力→仰拍 vs 情绪→特写）。按固定优先级让步：

```
情绪基调 > 信息层级 > 权力关系
```

先满足情绪，再满足信息，最后让步权力。**这是确定性来源：同样输入永远同样输出。**

## 五、分镜片段三档决策法（选档 → 定图数）

> 分镜片段时长非固定，按信息量选三档：5s / 10s / 15s。分镜图 = 关键帧，不是「镜头数 × 固定 1 张」。

### 5.1 选档：数信息点定档位

| 档位 | 内容特征 | 典型例子 | 信息点 |
|:---:|---------|---------|:---:|
| 5s | 单一动作 / 反应 / 单个镜头 | 一个眼神、一次受击、空镜转场 | 1 个 |
| 10s | 一组连贯动作 / 简短对白 | 起身→走到门边→回头；2-3 句台词 | 2-3 个 |
| 15s | 完整场景段 / 多镜头叙事 | 完整对话、情绪转折、小高潮 | 4+ 个 |

判断口诀：一个动作 → 5s；一组动作/几句台词 → 10s；完整情节段 → 15s。

### 5.1.1 档位建议与确认（先建议，后定档）

选档是**建议**，不是终审。智能体拆完剧本片段后，先输出《档位建议表》，使用者确认后才最终定档：

```
【分镜片段档位建议】共 N 个片段

| 片段   | 信息点（列出）     | 建议档位 | 理由         |
|--------|------------------|:---:|-------------|
| 片段1  | 起身/走到门边/回头 | 10s | 一组连贯动作 |
| 片段2  | 一个眼神         | 5s  | 单一反应     |
```

**确认方式**：
- 回复「采纳」→ 全部按建议执行
- 指定微调（如「片段2改15s」「整体统一10s」）→ 按调整执行
- **未确认前不进入 5.2 定图数、不出提示词**

**触发时机**：① 拆完片段后主动给建议表；② 使用者问「某片段多少秒」时单独给该片段建议。

### 5.2 定图数：档位 × 节奏交叉表

| 档位 | 慢（情绪/氛围） | 中（对白） | 快（动作/打戏） |
|:---:|:---:|:---:|:---:|
| 5s | 1~2 张 | 2 张 | 3~6 张 |
| 10s | 2~4 张 | 3~5 张 | 5~10 张 |
| 15s | 4~8 张 | 5~8 张 | 10~20 张 |

### 5.3 每镜头关键帧修正（运镜复杂度）

| 镜头类型 | 关键帧数 | 画哪些 |
|---------|:---:|------|
| 固定机位（对白正反打、静物） | 1 张 | 一张代表整个镜头 |
| 简单运镜（推 / 拉 / 摇） | 2 张 | 起幅 + 落幅 |
| 复杂运镜（环绕 / 跟拍长镜） | 3 张 | 起幅 + 转折 + 落幅 |
| 动作镜头（打斗 / 爆发） | 2~3 张 | 起势 + 动作顶点 + 受击 |

### 5.4 视频工具换算（Seedance / 可灵 / 万相）

```
段数 = 档位 ÷ 每段 3~5 秒
5s 档 → 1 段 → 2 张首尾帧
10s 档 → 2~3 段 → 4~6 张
15s 档 → 3~5 段 → 6~10 张
（单段时长上限：Seedance 4-30s / 可灵 5·10·15s / 万相按时间戳）
```

### 实例

**15s 对白戏**：中节奏 → 6 镜头 → 全固定机位每镜 1 张 → **6 张**。
**15s 打戏**：快节奏 → 12 镜头 → 8 动作镜×2 + 4 过渡镜×1 → **20 张**（上限）；给视频工具 → 5 段 × 2 = **10 张控制图**。
**5s 反应镜头**：单一信息点 → 5s 档 → **1 张**（一个眼神特写）。

## 六、全局负面清单（跨片规避 · 输出时合并）

> 来源：视频学习五维框架维度五 5.3「规避点」汇总 + 点火实测踩坑。分两层使用，**A 层进负面词，B 层进决策**。

### A 层：提示词负面词（写进 negative prompt）

> 仅即梦 image2 / Seedream 5.0 Pro 使用（模型卡支持负面词）；**Flux 不写**（死锁规则）。
> 输出时与角色锚定卡「禁止表演」转换的负面词**合并输出**。

| 负面词 | 规避的问题 | 置信度 |
|--------|-----------|:---:|
| deformed, bad anatomy, extra fingers | 肢体畸变（生图通病） | 📖官方 |
| text, watermark, logo | 乱入文字水印 | ✅实测 |
| oversaturated, overexposed | 过曝过饱和（夜景/月光戏高发） | ✅实测 |
| stiff expression, frozen face | 表情僵硬（视频生成口型/表情高发） | 🧪传闻 |
| （视频学习规避点回填区 · 只追加） | | |

### B 层：决策规避（生成设计时避免的模式，不是负面词）

| 禁止模式 | 原因 | 来源 |
|---------|------|------|
| 长镜头超 8s 无信息量 | 节奏拖沓，观众流失 | 五维框架 5.3 |
| 情绪无铺垫直接爆发 | 表演过火，可信度崩 | 五维框架 5.3 |
