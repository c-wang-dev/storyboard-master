# 多帧一致性策略库

> 分镜最头疼的问题：逐帧独立生成，同一个角色的脸、衣服、画风会漂移（「换脸」）。
> **本库按模型的一致性机制分档**：6 个选定模型都用「参考图 / 首帧」机制锁角色，**不再是 SD 时代的 IP-Adapter/LoRA/ControlNet**（那些是开源本地模型的概念）。

## 一、核心原则（全模型通用）

1. **定妆照先行**：任何角色先出一张「定妆照」（正脸、无遮挡、均匀打光），作为全片一致性锚点。
2. **场景图先行**：任何主场景先出一张「场景设定图」（全景、无人物、全貌构图），作为该场景多机位一致性锚点——**同一场景所有分镜帧共用同一张场景图参考**，换机位不换场景。
3. **同一参考图贯穿全片**：所有镜头共用同一张定妆照/场景图，不许中途换脸换场景。
4. **首帧即身份**：生视频时，首帧图 = 分镜图 = 角色身份源，后续靠参考图/元素参考锁住。
5. **一次改一个变量**：改动作不改脸，改场景不改角色，否则漂移无法归因。

## 二、生图模型的一致性机制

| 模型 | 一致性机制 | 用法 |
|------|-----------|------|
| GPT-Image-2 | 参考图（图生图） | 上传定妆照做参考图，prompt 描述变化 |
| Seedream 5.0 Pro | 参考图 ≤10 张 | 多张参考图分别锁脸/服装/道具 |
| Flux | 角色 LoRA + 图生图 | 训练角色 LoRA（25-30 张训练图），或图生图 denoise 0.7-0.9 |

> 关键：GPT-Image-2 / Seedream 的参考图机制**取代**了 IP-Adapter——不用写权重，直接传图（GPT-Image-2 支持 1-16 张，每次迭代重申「保留清单」防漂移）。

## 三、生视频模型的一致性机制

| 模型 | 一致性机制 | 用法 |
|------|-----------|------|
| Seedance 2.5 | 首帧 + 参考图（≤30 张） | @Image1 作首帧锁定身份，参考图锁服装/场景 |
| 可灵 3.0 | **首帧（必须）** + element reference | 图生视频必须加首帧；开 element reference 锁角色 |
| 通义万相 2.7 | 首帧 / 参考图 / LoRA 微调 | 首帧图 + 参考图，需要精确角色可 LoRA 微调 |

## 四、分镜大师落地用法（按选定模型输出）

```
【一致性建议】（按选定模型填，其他模型不出现）
- 参考图1：角色定妆照（同一张贯穿全分镜，锁脸源）
- 参考图2：场景设定图（同场景多机位贯穿，锁场景全貌）
- 逐项锚点清单（防漂移，蒸馏自 director-skills Continuity）：
  - 身份：角色名 + 锚定卡标志微表情（如沈孤鸿眉心常蹙）
  - 服装：颜色/款式/破损状态（逐帧一致，片段4 黎三袖口裂开需延续）
  - 道具：刀/刃/伤疤位置状态（逐帧一致）
  - 位置：场景内相对位置（轴线不跳）
- [Seedance（即梦视频）] 首帧 = 对应分镜图
- [可灵] element reference 开启
- [Flux] 角色 LoRA 0.6 + 图生图 denoise 0.75
```

> **资产图链（生图全流程，顺序不可颠倒）**：
> ① 定妆照（正妆造，锁脸源）→ ② 三视图（锁服装全貌）→ ③ 场景设定图（锁场景全貌）→ ④ 分镜帧 = 帧提示词 + 参考图（定妆照 + 场景图）
> 跳过 ①②③ 直接文生图 = 每次新脸 + 服装漂移 + 场景漂移（点火教训）。

> **场景锚点规则（防场景漂移）**：
> 1. **时间同义归一**：夜晚/月夜/深夜/月光夜/黄昏后 → 「夜」；白昼/白天/正午/午后 → 「日」。同一地点的时间变体（"屋脊·夜晚""屋脊·月夜"）是**同一个场景**
> 2. **场景图按地点出**：同一地点只出一张设定图，时间取主氛围；所有机位/景别共用
> 3. **帧提示词场景名统一**：帧内场景描述用场景设定图的标准名（屋脊/古镇青石长街…），禁止变体命名（屋顶/房顶/屋檐→屋脊）

> 与 [[性格范式库]] 的角色锚定卡配合：锚定卡给「角色是谁、怎么演」，本库给「怎么让角色在画面里不漂」。
