# 场景配方库

> 高频场景 × 选定模型的组合配方卡。每张卡是「大脑」直接抄进提示词包的完整参数块。
> 配方卡格式：场景 → 模型（见 [[参数速查表]] 模型卡）→ 一致性（见 [[多帧一致性策略库]]）→ 提示词要点。
> 置信度：📖 官方 / ✅ 社区实测 / 🧪 待实战验证。实战后回写修正。

## 配方卡 01：角色特写 · 跨帧锁脸（⭐ 最高频）

| 项 | 配置 |
|----|------|
| 模型 | Seedream 5.0 Pro（或GPT-Image-2） |
| 一致性 | 上传角色定妆照做参考图（≤10 张） |
| 参考图要求 | 正脸、无遮挡、均匀打光，脸占画面 25-40% |
| 提示词要点 | 自然语言，主体放句首，描述变化（服装/表情/场景） |
| 来源 | ✅ 社区实测 2026-08 |

## 配方卡 02：影视级场景氛围图（生图）

| 项 | 配置 |
|----|------|
| 模型 | Flux（自然语言长句） |
| 参数 | CFG 3.5 / euler / Steps 28 / 1024×1024 |
| 提示词 | 主体 + 场景 + 光线 + 相机视角 + 材质（不写负面词） |
| 来源 | ✅ 10b.ai 实测 2025-12 |

## 配方卡 03：写实视频 · 人物动作（生视频）

| 项 | 配置 |
|----|------|
| 模型 | 可灵 3.0（图生视频） |
| 首帧 | 必须，用角色定妆照或分镜图 |
| 一致性 | element reference 开启 |
| 时长 | 5 秒（动作）/ 10 秒（完整动作） |
| 提示词 | motion prompt：Subject + Movement + Background（只描述运动） |
| 来源 | ✅ 社区实测 2026-08 |

## 配方卡 04：叙事短片（生视频）

| 项 | 配置 |
|----|------|
| 模型 | Seedance 2.5 |
| 首尾帧 | @Image1 首帧 / @Image2 尾帧（同比例） |
| 时长 | 4-30 秒 |
| 提示词 | 三层：概述 + 分镜时间戳 + 一致性说明 |
| 音频 | 支持环境音/对白（plain 指令） |
| 来源 | 📖官方 + ✅社区 2026-08 |

## 配方卡 05：多镜头叙事（生视频）

| 项 | 配置 |
|----|------|
| 模型 | 通义万相 2.7 |
| 多镜头 | 时间戳分镜："第1镜头[0-3秒] 全景：…" |
| 提示词 | 主体 + 场景 + 运动 + 美学控制 + 风格化 |
| 负面词 | 支持（≤500 字符） |
| 来源 | 📖官方 2026-08 |

## 配方卡 06：打戏分镜（生视频）

| 项 | 配置 |
|----|------|
| 模型 | Seedance 2.5 或 可灵 3.0 |
| 结构 | 「起势 → 动作顶点 → 受击反馈」三短切 |
| 首帧 | 同角色定妆照贯穿全部分镜 |
| 提示词 | 运镜术语：camera arc / handheld follow / slow push-in |
| 来源 | ✅ 社区实测 + 知识库镜头规律 |
