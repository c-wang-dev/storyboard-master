# 视频学习五维框架

> **用途**：分镜大师收到视频样本时，按本框架 5 个维度逐层分析，提炼为可复用规则，归档到知识库对应文件，供后续生成新剧本时自动调用。
> **核心原则**：不截图照搬人脸，而是把视频里的表演、视听、美术、节奏、流水线规律提炼成"规则"。每部视频归档一份，规则沉淀进通用库。
> **归档位置**：本文件为分析框架与规则汇总；每部视频的完整分析归档到 `视频学习记录/<片名>-<日期>.md`；可复用技法从记录**回填主库实例区**——性格绑定型微表情追加到 `性格范式库.md` 对应条目「实例归档」区，通用肌肉层细节追加到 `角色微表情库.md`，画风实例追加到 `风格参考库.md` §六 画风实例归档区，光影实例追加到 `光影与色彩.md` §六 实例归档区，运镜实例追加到 `镜头语言.md` §七 实例归档区，节奏/转场实例追加到 `转场与片段衔接库.md` §四，音频节奏实例追加到 `音频指令配方库.md` §三，规避点追加到 `分镜决策引擎.md` §六 全局负面清单（归档去向总表见 [[视频学习记录/README]]）。**回填主库前必过 [[知识库治理规则]] 闸门 A（查重合并 / 冲突仲裁 / 三要素强制），容量红线与周期治理按该规则执行**。

## 维度一：视听语言（镜头层 · 最核心）

> 分析工具：ffprobe 读参数 → ffmpeg 场景检测抽帧 → 逐镜头标注。

### 1.1 景别占比统计
- 逐镜头记录景别：大远景 / 远景 / 全景 / 中全景 / 中景 / 中近景 / 近景 / 特写 / 插入镜头
- 统计各景别**时长占比**（不是镜头数占比）：`全景 10% / 中近景 60% / 特写 30%`
- 记录规律：如"情绪爆发点大量特写""叙事段以中近景为主，大远景极少"

### 1.2 镜头时长
- 平均镜头时长：`平均 3.2s/镜头`
- 分场景类型统计：对话镜头 2-3s、打斗/冲突镜头 1-1.5s、慢镜头出现时机
- 最长/最短镜头及其功能：如"开场 8s 长镜头建立环境"

### 1.3 机位与运镜规则
- 机位高度：平视 / 仰拍（权力感）/ 俯拍（弱势感）
- 运镜类型统计：固定镜头 X%、手持呼吸抖动 X%、缓慢推拉 X%、横移 X%、环绕 X%
- 人物对话模式：是否正反打？过肩镜头（OTS）用得多不多？有没有越轴？
- 特殊运镜习惯：如"冲突前必有一组快速推镜""悬念处固定机位静默 3s"

### 1.4 剪辑逻辑
- 切换时机：台词停顿 / 情绪转折 / 动作卡点 / 声音先入
- 转场方式：硬切为主还是叠化、闪白、匹配剪辑
- 节奏曲线：全片快慢交替规律，高潮段平均镜头时长

### 📤 输出：镜头选择规则
```
【该片镜头规则】
- 叙事段：中近景为主，正反打+过肩，平均 3s
- 情绪爆发点：切特写，固定机位或缓推
- 冲突段：快切 1-1.5s，手持抖动
- 慢镜头时机：角色内心转折时
→ 写新剧本时自动套用这套剪辑习惯
```

## 维度二：视觉美术风格（绘图提示词内核）

> 分析工具：抽帧后逐帧看画面，对比多帧取稳定特征。

### 2.1 人物画风
- 风格类型：3D 写实 / 厚涂 / 二次元 / 三渲二 / 水墨…
- 五官特征：眼型（杏眼/丹凤眼）、鼻型、脸型（瓜子/圆/方）
- 皮肤质感：细腻无瑕 / 肌理真实 / 赛璐璐色块
- 头发表现：发丝细节 / 色块

### 2.2 光影
- 冷暖调：冷调 / 暖调 / 中性
- 光质：硬阴影（写实戏剧感）/ 柔光影（唯美）
- 主光源方向：顶光 / 侧光 / 逆光 / 伦勃朗光
- 特殊处理：胶片颗粒、雾化、辉光、LUT 滤镜（S-Cinetone 之类）、体积光

### 2.3 色调
- 整体色偏：冷青灰蓝 / 暖黄 / 高饱和 / 低饱和
- 对比度：高对比（明暗分明）/ 低对比（柔和统一）
- 主色+辅色方案：如"青橙配色：阴影青、高光橙"

### 2.4 场景渲染风格与融合
- 场景类型与细节密度：写实建模 / 手绘背景 / 风格化
- 人物与场景融合方式：一体渲染（同光源同材质）/ 人物突出背景虚化 / 2D 人物+3D 背景
- 景深处理：大光圈虚化 / 全景深

### 2.5 画面参数
- 分辨率：1080P / 2K / 4K
- 画幅：16:9 横屏 / 9:16 竖屏短剧
- 帧率：24fps（电影感）/ 30fps / 60fps（流畅）
- 镜头语言附件：景别倾向、焦段感（广角畸变 / 长焦压缩）

### 📤 输出：绘图 Prompt 模板
```
【该片视觉模板】
- 画风：3D 写实 + 厚涂质感
- 人物：杏眼、瓜子脸、皮肤细腻
- 光影：暖调柔光 + 逆光轮廓，黄金时段
- 色调：高饱和暖黄 + 青橙对比
- 参数：1080P, 9:16, 24fps
→ 生成提示词时直接作为画风前缀复用
```

## 维度三：表演与角色规则（角色性格塑造）

> 分析工具：聚焦人物镜头逐帧看表演。先判定角色**性格范式**（对照 `性格范式库.md` 的 8 个条目），再参考 `角色微表情库.md` 定位微表情细节。

### 3.1 人物微表情逻辑（重点）
- 按角色提取：某角色生气时**具体**是什么样子（不是"统一怒脸"）
  - 轻微愤怒：眉头怎么动？眼神温度？
  - 压抑悲伤：嘴角变化幅度？眼皮状态？
  - 不同情绪下眼皮、嘴唇、头部姿态差异
- 角色专属小动作：摸鼻、舔牙、眨眼频率、说话时的手势
- 情绪切换习惯：由怒转哀时先哪个部位动？

### 3.2 肢体语言
- 对话时手势：幅度大 / 克制 / 无手势
- 身体倾斜：前倾（亲近/施压）/ 后仰（防御/轻蔑）
- 站立姿态：重心、站姿开合、手部位置（插兜/环抱/自然）

### 3.3 角色镜头偏向
- 主角：什么时刻给特写？（情绪爆发 / 决策瞬间 / 高光时刻）
- 配角：多用什么景别？（中景为主，少特写）
- 反派：给不给特写？何时给？

### 📤 输出：表演规则
```
【该片表演规则】
- 角色A（主角）· 性格范式：隐忍坚毅型 · 生气时先眯眼再低眉，压抑型；特写给在落泪前0.5s
- 角色B（反派）· 性格范式：背地阴狠型 · 永远微笑但眼神温度降低，配单侧挑眉
- 情绪转折习惯：先动眉眼后动嘴
→ 生成新剧本人物提示词时，先锁性格范式（建角色锚定卡），再套用
→ 新观察到的微表情实例分层归档：性格绑定型追加到 `性格范式库.md` 对应条目「实例归档」区；通用肌肉层细节追加到 `角色微表情库.md` 对应条目
```

## 维度四：音频节奏（视频生成 + 配音）

> 分析工具：ffmpeg 提取音轨 → showwaves 波形图 + showspectrum 频谱图 → 逐段分析。

### 4.1 BGM 使用时机
- 起 BGM 的位置：开场即起 / 事件触发 / 情绪转折前
- 分场景配乐类型：冲突（紧张低频）/ 对话（轻配乐或无）/ 独处（氛围垫乐）
- BGM 起落方式：渐入渐出 / 硬切 / 卡点爆点

### 4.2 音效
- 环境音密度：有无人声环境（街道/雨声/风声）
- 动作音效：打斗、碰撞、脚步声的强化程度
- 音效卡点：是否与剪辑点同步

### 4.3 配音节奏
- 台词语速：整体快慢 + 分情绪语速
- 停顿位置：句间停顿时长、强调前停顿
- 情绪起伏：音量与音调的变化曲线
- 特殊习惯：气声、叹气、笑声的位置

### 📤 输出：音频节奏模板
```
【该片音频节奏】
- BGM：开场3s内起，冲突段低频加压，对话段音量压低
- 音效：动作音效强化+卡剪辑点，环境音全程垫底
- 配音：对话语速中等，爆发句前停顿0.5s，高潮句音量+6dB
→ Seedance/可灵/万相 生成视频时音频尽量复刻样片节奏
```

## 维度五：业务流水线隐性规则（最易被忽略）

> 分析工具：通观全片 + 对照剧本，找映射规律。

### 5.1 剧本→分镜映射关系
- 一句台词对应几个镜头？（对话戏拆法：说话者+反应镜头+插入镜头）
- 大段内心独白怎么拆？（空镜+人物特写+回忆闪回）
- 动作描写 → 画面：如何分解成起手/过程/落点
- 心理描写 → 画面：用什么视觉手段外化（表情特写/环境隐喻/光影变化）

### 5.2 资产复用逻辑
- 同一角色不同场景，五官一致性如何保证？（同角度的标准脸/特征点固定）
- 服装道具如何统一？（同一套装在不同场景的细节一致性）
- 同一场景不同时间（白天/夜晚）的复用与变化

### 5.3 规避点（负面清单）
- 该片哪些镜头效果差？（穿帮、表演过火、构图失衡、节奏拖沓）
- 明确禁止智能体复现的镜头模式
- 观众负面反馈点（如弹幕吐槽"表情僵硬""转场突兀"）

### 📤 输出：流水线规则
```
【该片流水线规则】
- 一句台词=2-3镜头（说话者中近景+反应者近景）
- 内心独白=人物特写+空镜+闪回三件套
- 角色五官：固定三视图特征参数，跨场景复用
- 规避：禁止长镜头超过8s无信息量；禁止情绪无铺垫直接爆发
```

## 附：视频归档格式（每部视频一份）

```markdown
# 《片名》- 视频学习分析

- 来源：抖音/红果/本地
- 时长：3:24 | 分辨率：1080x1920 | 画幅：9:16
- 分析日期：2026-08-14

## 一、视听语言
（景别占比表 + 镜头时长统计 + 运镜规则 + 剪辑逻辑）

## 二、视觉美术风格
（画风/光影/色调/场景/参数 + 最终 Prompt 模板）

## 三、表演与角色规则
（按角色列性格范式标签 + 微表情逻辑 + 肢体语言 + 镜头偏向）

## 四、音频节奏
（BGM/音效/配音节奏 + 节奏模板）

## 五、流水线隐性规则
（剧本→分镜映射 + 资产复用 + 规避点）

## 六、可复用标签
#古风 #虐恋 #3D写实 #暖调逆光 #中近景为主 #快切冲突 #压抑型表演
```

> **标签规范**：每部视频归档时生成 5-10 个标签，格式 `#题材 #风格 #画风 #光影 #景别习惯 #剪辑习惯 #表演类型`，供分镜大师生成时按标签精准匹配参考案例。
